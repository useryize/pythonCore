## 📖 二、知识讲解

### 2.1 索引

**一句话定义**：用整数下标访问序列中某个位置的元素，从 0 开始。

```python
s = "Python"
print(len(s))      # 6     长度
print(s[0])        # 'P'   第一个
print(s[5])        # 'n'   最后一个（因为下标从 0 开始）
print(s[-1])       # 'n'   倒数第一个
print(s[-6])       # 'P'   倒数第六个 == s[0]
```

**⚠️ 高频错误：用 `len(s)` 当最后一个下标**：

```python
s = "Python"
print(s[len(s)])   # IndexError！最后一个是 s[len(s) - 1]
# 所有语言里最后一个下标都是 len - 1，Python 也不例外
```

**为什么下标从 0 开始**：

下标的本质是「**偏移量**」——「当前元素前面有几个元素」。

- 第一个元素前面有 **0** 个元素 → 下标 0
- 第二个元素前面有 **1** 个元素 → 下标 1

这个心智模型比「第 i 个元素」更贴近内存寻址：拿到内存地址后，加上偏移量就是目标地址。如果从 1 开始，则「第 i 个」和「偏移 i」永远差 1，所有指针运算都要多减一次，语言设计者选择了消除这个冗余。

Python 也支持负数下标，规则是「从末尾往回数」，`s[-1]` 等价于 `s[len(s) - 1]`。

**越界行为**：

```python
s = "Python"
try:
    s[10]
except IndexError as exc:
    print(exc)     # string index out of range

try:
    s[-10]
except IndexError as exc:
    print(exc)     # string index out of range（负数越界的提示更长，因为要算负索引）
```

**⚠️ 别混淆「索引」和「`index()`」**：

```python
s = "Hello Python"
print(s[0])             # 'H'       取「第 0 个字符」
print(s.index("Py"))    # 6         找「子串 Py 的起始位置」
# 一个是取字符，一个是找位置，完全不同的操作
```

### 2.2 切片

**一句话定义**：`s[start:stop:step]` 返回一个新的字符串，取下标在 `[start, stop)` 区间内、按 `step` 步长的子序列。

**核心语义：左闭右开（`[start, stop)`）**。

```python
s = "abcdefghij"
print(s[:4])       # 'abcd'   [0,4)   0 1 2 3，不含 4
print(s[4:])       # 'efghij' [4,10) 4 到末尾
print(s[2:8])      # 'cdefgh' [2,8)
print(s[:])        # 完整复制一份新字符串
```

**省略参数的约定**：

| 写法 | 等价于 |
| --- | --- |
| `s[:n]` | `s[0:n]` |
| `s[n:]` | `s[n:len(s)]` |
| `s[:]` | `s[0:len(s)]`（完整复制） |
| `s[::2]` | `s[0:len(s):2]` |

**步长**：

```python
s = "abcdefghij"
print(s[::2])      # 'acegi'    隔一个取一个
print(s[1::2])     # 'bdfhj'    从下标 1 开始隔一个
print(s[::-1])     # 'jihgfedcba'  倒序（反转字符串的经典写法）
print(s[::3])      # 'adgj'
print(s[-3:])      # 'hij'      最后三个
print(s[:-3])      # 'abcdefg'  去掉最后三个
```

**⭐ 切片永不越界，索引会越界**（这是切片最重要的性质）：

```python
s = "abcdefghij"
print(s[5:100])    # 'fghij'    stop 超出长度，自动截到末尾，不报错
print(s[100:])     # ''         start 超出长度 → 空字符串
print(s[-100:])    # 'abcdefghij'  负 start 被规范到 0
print(s[8:3])      # ''         start > stop → 空字符串，也不报错
# 对比：s[100] 会抛 IndexError

# 为什么？切片内部做的是「钳制」处理：
#   把 start 和 stop 都限制在 [0, len(s)] 范围内
# 这让切片特别适合写「不知道边界」的通用代码
```

**实战应用**：

```python
card = "110101199003074321"
# 身份证遮蔽：前 6 位保留，后 4 位保留，中间遮掉
masked = card[:6] + "*" * len(card[6:])
print(masked)      # '110101********4321'

# 只露首尾
print(card[:3] + "*" * 10 + card[-4:])    # '110***********4321'

# 每隔一位取一位（提取奇数位字符）
print(card[::2])   # '1019003421'

# 反转
print(card[::-1])  # '123470309910101011'

# 去首尾各 2 个字符
print("__hello__"[2:-2])     # 'hello'
```

**处理多行文本时**：

```python
text = "第一行\n第二行\n第三行"
lines = text.splitlines()
print(lines[0])     # '第一行'   ⚠️ 用 [0] 是第一行，[-1] 才是最后一行
print(lines[-1])    # '第三行'
```

### 2.3 字符串不可变性的三个后果

**一句话定义**：`str` 一旦创建，其字符内容永远不能修改；所有「修改」方法都返回**新对象**。

```python
s = "hello"
print(s.upper())    # 'HELLO'
print(s)            # 'hello'   原串纹丝不动

# 不存在 s[0] = 'H' 这种写法
try:
    s[0] = "H"
except TypeError as exc:
    print(exc)      # 'str' object does not support item assignment

# 正确做法：拼接或切片
print("H" + s[1:])  # 'Hello'
```

**为什么设计成不可变**：

1. **安全性**：不可变对象可以被多处同时引用而不用担心「有人在背后改了它」。传字符串给函数不用担心它被篡改。
2. **可哈希**：不可变对象才能作为字典的键、放进集合（L08 详讲）。
3. **可缓存**：CPython 可以安全地驻留（intern）相同内容的字符串字面量，节省内存。

#### 后果 1：循环里 `+=` 是 O(n²)

```python
# ❌ 慢：每次 += 都新建一个完整的字符串，并把已有的全部复制一遍
slow = ""
for ch in text:
    slow += ch        # 第 n 轮要复制 n 个字符，总计 O(n²)

# ✅ 快：先收集到列表，最后一次性 join（只新建一次，O(n)）
parts = []
for ch in text:
    parts.append(ch)
fast = "".join(parts)
```

对 10 万字符的文本，第一种写法约需 50 亿次字符复制，第二种只需 10 万次。这就是「不要在循环里拼接字符串」这条经验法则的来源。

进一步优化可以用 `io.StringIO`（内存中的文本缓冲区），它在反复写入时不会产生中间字符串。

#### 后果 2：必须传参的方法可以传 `0` / `None` 表示「保持原样」

```python
# str.replace 的第三个参数是 count（替换次数），传 0 表示「一个都不替换」
print("aaa".replace("a", "b", 0))    # 'aaa'   等于没改

# split 的 maxsplit 同理
print("a,b,c".split(",", 0))         # ['a,b,c']  不切
```

#### 后果 3：链式调用是安全的

```python
raw = "  Hello, World!  "
# 每一环都返回新对象，你从未对同一对象发起两次修改
cleaned = raw.strip().replace("World", "Python").upper()
print(raw)        # '  Hello, World!  '   原串未变
print(cleaned)    # 'HELLO, PYTHON!'
```

**真正危险的是把结果赋回原变量名**：

```python
# 这种写法让人误以为「改了原串」，实际却是换了个新串
s = "hello"
s = s.upper()
# 读代码的人会困惑：s 到底是原来那个还是新的？
# 更好的命名：upper_s = s.upper()，让「产生了新值」这件事显式化
```

### 2.4 字符串方法全景（按用途分类）

死记硬背方法列表是低效的。**按用途分类**才是可迁移的知识。

#### 查：找位置、判断包含

| 方法 | 返回 | 找不到时 |
| --- | --- | --- |
| `s.find(sub)` | 起始下标 | 返回 `-1` |
| `s.index(sub)` | 起始下标 | **抛 `ValueError`** |
| `s.rfind(sub)` | 从右往左的下标 | 返回 `-1` |
| `s.rindex(sub)` | 从右往左的下标 | 抛 `ValueError` |
| `s.count(sub)` | 出现次数 | 返回 `0` |
| `sub in s` | `bool` | 返回 `False` |
| `s.startswith(p)` | `bool` | `False` |
| `s.endswith(p)` | `bool` | `False` |

**`find` vs `index` 的选择**：

```python
s = "Hello"
idx = s.find("x")
if idx >= 0:                 # ✅ find：需要自己判断
    print(s[idx:])

idx = s.index("x")           # ❌ 不存在就崩

s2 = "Hello"
try:
    idx = s2.index("H")      # ✅ index：保证存在时才用
except ValueError:
    print("未找到")
```

**⚠️ `find` 返回 `-1` 的陷阱**：把 `-1` 当下标传给 `s[-1]` 会静默得到**最后一个字符**，而不是报错：

```python
s = "Hello"
idx = s.find("z")        # -1
print(s[idx:])           # 'o'   ⚠️ 这是「最后一个字符」，不是你想要的！
# 正确写法
if idx != -1:
    print(s[idx:])
```

#### 转：大小写、首尾空白、类型转换

```python
s = "python is Fun"
print(s.upper())             # 'PYTHON IS FUN'
print(s.lower())             # 'python is fun'
print(s.capitalize())        # 'Python is fun'    只首字母大写
print(s.title())             # 'Python Is Fun'    每个单词首字母大写
print(s.swapcase())          # 'PYTHON IS fUN'    大小写互换

t = "  hi  "
print(t.strip())             # 'hi'   去首尾所有空白
print(t.lstrip())            # 'hi  ' 只去左
print(t.rstrip())            # '  hi' 只去右
print("xxhixx".strip("x"))    # 'hi'   传参时是「字符集」，不是前后缀

# 3.9+：只去掉一次前缀/后缀
print("Hello World".removeprefix("Hello "))   # 'World'
print("report.pdf".removesuffix(".pdf"))      # 'report'
# ⚠️ 只去一次。"aXbXc".removeprefix("aX") → 'bXc'（不是 'c'）
```

**`strip` 传参的语义**：

```python
# 传的是「要剥离的字符集合」，不是「前缀/后缀」
print("hello".strip("lo"))         # 'hel'   l 和 o 任意组合都剥
print("helloworld".strip("lo"))    # 'weld'  ⚠️ 两端都剥，不是剥掉前缀后缀
# 只想去掉固定前后缀要用 removeprefix/removesuffix
```

#### 改：返回新字符串

```python
print("a-b-c".replace("-", "+"))       # 'a+b+c'
print("a-b-c-d".replace("-", "+", 1))  # 'a+b-c-d'   只换第一处
print(", ".join(["a", "b", "c"]))      # 'a, b, c'
print("42".zfill(5))                   # '00042'  ⚠️ zfill 只支持 '0' 填充
print("ab".center(9, "*"))             # '***ab***'
print("ab".ljust(5, "."))              # 'ab...'
print("ab".rjust(5, "."))              # '...ab'
```

#### 拆：切分

```python
print("a,b,c".split(","))             # ['a', 'b', 'c']
print("a b  c".split())               # ['a', 'b', 'c']   按任意空白切，自动合并连续空白
print("a\nb\tc".split())              # ['a', 'b', 'c']   同时处理换行和制表
print("a,b,c".split(",", 1))          # ['a', 'b,c']      最多切 1 刀
print("a,b,c".rsplit(",", 1))         # ['a,b', 'c']      从右边切
print("第一行\n第二行".splitlines())    # ['第一行', '第二行']  自动处理各种换行符
print("a=b=c".partition("="))         # ('a', '=', 'b=c')   只切一刀，返回三元组
print("a=b=c".rpartition("="))        # ('a=b', '=', 'c')
```

**`split` 与 `splitlines` 的区别**：

```python
# splitlines 各种换行都认（\n \r\n \r ），且不会留下空字符串
print(repr("a\nb".splitlines()))      # ['a', 'b']
print(repr("a\nb\n".splitlines()))    # ['a', 'b']    末尾换行不产生空串

# split("\n") 遇到 \r\n 会留下 \r
print(repr("a\r\nb".split("\n")))     # ['a\r', 'b']  ⚠️ 有残留字符

# splitlines() 还能识别其他 Unicode 换行符（\v \f \x1c 等）
print(repr("a\x0bb".splitlines()))    # ['a', 'b']
```

#### 判：返回 `bool`

| 方法 | 含义 |
| --- | --- |
| `s.isalpha()` | 全是字母 |
| `s.isdigit()` | 全是 0-9 |
| `s.isnumeric()` | 全是数字（含中文数字、分数等，更宽） |
| `s.isalnum()` | 全是字母或数字 |
| `s.isspace()` | 全是空白 |
| `s.isupper()` / `s.islower()` | 全大写 / 全小写 |
| `s.istitle()` | 每个单词首字母大写 |
| `s.isascii()` | 纯 ASCII |
| `s.isidentifier()` | 能否作 Python 标识符（变量名） |
| `s.isprintable()` | 是否全部可打印 |
| `s.isdecimal()` | 全是十进制数字 |

**⚠️ `isdigit` vs `isnumeric`**：

```python
print("123".isdigit(), "123".isnumeric())       # True True
print("²".isdigit(), "²".isnumeric())   # True True   上标数字
print("一二三".isdigit(), "一二三".isnumeric())       # False True   中文数字
print("½".isdigit(), "½".isnumeric())   # False True   分数
# 结论：isdigit 更严格（只认 0-9），isnumeric 范围更广
```

**判断字符串是否为合法的整数**（处理用户输入常用）：

```python
import re

def is_integer(s: str) -> bool:
    """严格判断是否为十进制整数（允许正负号和首尾空白）。"""
    return bool(re.fullmatch(r"[+-]?\d+", s.strip()))

print(is_integer("42"))     # True
print(is_integer("-42"))    # True
print(is_integer(" 42 "))   # True
print(is_integer("4.2"))    # False
print(is_integer("42元"))   # False
```

### 2.5 f-string 进阶

#### 用法 1：嵌套引号的版本要求

```python
name = "李雷"
items = {"苹果": 3, "香蕉": 5}

# 外双引号 + 内单引号（任何版本都能用）
print(f"数量：{items['苹果']}")

# 外单引号 + 内双引号（任何版本都能用）
print(f'数量：{items["苹果"]}')

# ⚠️ 同引号嵌套：3.12 之前会报 SyntaxError
# print(f"{items["苹果"]}")            # Python 3.12 之前：SyntaxError
# Python 3.12+ 起由 PEP 701 放宽了这个限制

# 💡 最佳实践：超过一层嵌套就把值取到变量里
apple = items["苹果"]
banana = items.get("香蕉", 0)
print(f"苹果={apple} 香蕉={banana}")
```

#### 用法 2：调试用 `=` 与多行

```python
n = 42
print(f"{n=}")            # n=42
print(f"{n = }")          # n = 42   注意等号两侧空格会保留
print(f"{n = :>6}")       # n =    42   还能配合格式说明符

# = 与转换符配合，注意顺序是「= 在前，转换符在后」
s = "text"
print(f"{s = !r}")        # s = 'text'

# 多行 f-string 适合拼提示语
count = 3
total = 15.5
summary = f"""
    统计结果：
    数量：{count}
    合计：{total:.2f}
    平均：{total / count:.2f}
    """
print(summary)
```

#### 用法 3：条件表达式内嵌

```python
score = 85
print(f"{score} 分 → {'及格' if score >= 60 else '不及格'}")

# ⚠️ 三元作为子表达式时，优先级是陷阱（见 L02）
# f"{name or ('A' if cond else 'B')}" 会被解析成 name or (...)
# 正确做法是整个三元加括号
```

#### 用法 4：格式说明符实用组合

```python
price = 12345.678
rows = [
    f"{'原始':<12}{price}",
    f"{'千分位':<12}{price:,.2f}",
    f"{'百分比':<12}{0.8567:.2%}",
    f"{'科学计数':<12}{0.00012345:.3e}",
    f"{'十六进制':<12}{255:#06x}",
    f"{'定宽右对齐':<12}{'ab':>8}|",
    f"{'定宽居中':<12}{'ab':^8}|",
    f"{'补零':<12}{42:05d}",
]
for row in rows:
    print(row)
```

#### f-string 的边界

```python
# ⚠️ f-string 总是返回 str
v = 5
print(type(f"{v}"))      # <class 'str'>
print(int(f"{v}"))       # 5   需要别的类型要再包一层

# ⚠️ 3.12 之前，f-string 内部不能有反斜杠
# print(f"{'\n'}")       # Python 3.12 之前：SyntaxError

# ⚠️ 3.12 之前，f-string 内部不能有 # 注释
# print(f"{x  # 注释}")    # Python 3.12 之前：SyntaxError

# ⚠️ 表达式必须合法（不能是赋值语句）
# print(f"{x = 1}")       # SyntaxError
```

### 2.6 实战一：解析 CSV 行

**为什么需要标准库 `csv`**：

CSV 格式允许字段内部包含分隔符，只要用双引号包起来。自己 `split(",")` 会把引号内的逗号也切开：

```python
line = '韩梅梅,"北京,海淀",30'
print(line.split(","))     # ❌ ['韩梅梅', '"北京', '海淀"', '30']  引号内的逗号被误切

import csv
import io
fields = next(csv.reader(io.StringIO(line)))
print(fields)              # ✅ ['韩梅梅', '北京,海淀', '30']  正确识别
```

> 📌 **结论：真实项目处理 CSV 请永远用 `csv` 模块**，它正确处理引号、转义、嵌入换行等情况。

**单行解析 + 字段清洗的标准写法**：

```python
import csv
import io

HEADERS = ["姓名", "年龄", "城市", "职业", "手机"]
line = "张三,28,北京市,工程师,13800138000"

# 用 zip 把表头和数据对齐成字典
fields = next(csv.reader(io.StringIO(line)))
record = dict(zip(HEADERS, fields))

# 逐字段清洗
cleaned = {}
for key, value in record.items():
    value = value.strip()                # 去首尾空白
    if key == "年龄":
        try:
            value = int(value)           # 转 int，失败要兜底
        except ValueError:
            value = None                 # 不能让程序崩在脏数据上
    cleaned[key] = value
```

**⚠️ `zip` 静默截断的陷阱**：

```python
# 如果数据列数比表头少，zip 会静默丢弃多出来的表头
zip([1, 2, 3], ["a", "b"])          # [(1, 'a'), (2, 'b')]  3 和表头被静默丢弃

# 处理多行数据时，必须显式校验列数
def parse_table(lines: list[str]) -> list[dict[str, str]]:
    """把多行 CSV 解析成字典列表，自动跳过列数不符的行。"""
    rows = list(csv.reader(lines))
    if not rows:
        return []
    headers = rows[0]                          # 第一行是表头
    table = []
    for line_no, row in enumerate(rows[1:], start=2):
        if len(row) != len(headers):
            # ⚠️ 列数不齐是真实 CSV 最常见的问题，必须显式处理
            print(f"  ⚠️ 第 {line_no} 行列数不符（{len(row)} vs {len(headers)}），已跳过")
            continue
        table.append(dict(zip(headers, row)))
    return table
```

**分号分隔的 CSV**（欧洲常用）：给 `csv.reader` 传 `delimiter=";"`。

### 2.7 实战二：数据脱敏

**为什么需要脱敏**：日志、报表、截图都可能泄露个人信息。合规（个人信息保护法、GDPR）要求**最小化暴露**——只暴露业务必需的部分。

**手机号脱敏**：

```python
def mask_phone(phone: str) -> str:
    """手机号脱敏：13812345678 → 138****5678

    规则依据：前 3 位是运营商号段（需保留以识别运营商），
             后 4 位用于对账核验，中间 4 位完全遮蔽。
    """
    # ⚠️ 先校验，不合法就原样返回
    # 「脱敏失败时宁可不动也不要泄露」是安全设计的第一原则
    if len(phone) != 11 or not phone.isdigit():
        return phone
    return f"{phone[:3]}****{phone[-4:]}"
```

**身份证脱敏**：

```python
def mask_id_card(card: str) -> str:
    """身份证脱敏：110101199003074321 → 110101********4321

    前 6 位是行政区划码，后 4 位是校验码（用于验证有效性，必须保留），
    中间 8 位是出生日期，最敏感，必须遮蔽。
    """
    if len(card) != 18:
        return card
    return f"{card[:6]}{'*' * 8}{card[-4:]}"
```

**银行卡脱敏**（这是银行卡的标准规则）：

```python
def mask_bank_card(card: str) -> str:
    """银行卡脱敏：只保留后 4 位（银行标准规则）。"""
    digits = card.replace(" ", "")          # 先去掉可能的空格
    if not digits.isdigit() or len(digits) < 8:
        return digits
    return f"{'*' * (len(digits) - 4)}{digits[-4:]}"
```

**⭐ 幂等性（idempotent）**：

> **幂等**是指「执行一次和执行多次的结果相同」。

```python
once = mask_phone("13812345678")     # '138****5678'
twice = mask_phone(once)             # 输入已含 '*'，不是纯数字 → 原样返回
print(once == twice)                  # True ✅ 幂等
```

**为什么脱敏函数要幂等**：

1. **防止二次脱敏破坏数据**：日志系统可能已经脱敏过一次，如果又过一道，输出变成 `138*******678` 无法阅读。
2. **让函数可安全地多层调用**：日志框架、业务层、导出层都可能调用脱敏，无需担心重复。
3. **幂等是纯函数的重要标志**：纯函数（无副作用、相同输入得相同输出）是幂等的前提。

**工程实践三条原则**：

```text
原则 1：日志输出前脱敏，不依赖「调用方自觉」
        —— 在日志封装层统一脱敏，而不是让每个程序员记得手动处理
原则 2：只保留「业务必需」的部分，能少露就少露
原则 3：脱敏函数要幂等，已脱敏的再脱敏一次结果不变
```

## ⚠️ 四、常见错误清单

| 错误现象 | 原因 | 正确写法 |
| --- | --- | --- |
| `IndexError: string index out of range` | 用 `s[len(s)]` 当最后一个下标 | `s[len(s) - 1]` 或 `s[-1]` |
| `s[-1]` 得到「最后一个字符」但你以为在处理 `find` 的结果 | `find` 返回 `-1`，被当成合法负下标 | 先判断 `if idx != -1:` |
| `s[start:stop]` 少取了一个字符 | 切片是左闭右开，`stop` 不包含 | 记住 `[start, stop)`，或用 `stop = len(s) + 1` |
| `TypeError: 'str' object does not support item assignment` | 试图修改字符串 | `s = "H" + s[1:]` 或 `"".join()` 重建 |
| 循环里 `s += x` 运行极慢 | 每次都新建完整字符串，O(n²) | 先收集到列表，最后 `"".join()` |
| `"hello".strip("lo")` 得到 `'hel'` | `strip` 参数是「字符集」不是前后缀 | 用 `removeprefix` / `removesuffix`（3.9+） |
| `s.index(sub)` 抛 `ValueError` | 找不到会抛异常（设计如此） | 用 `find`（返回 -1）或 `try/except` |
| `s.split("\n")` 得到 `['a\r', 'b']` | `\r\n` 里的 `\r` 残留 | 用 `splitlines()` |
| `''.split(',')` 得到 `['']` 而不是 `[]` | 空串按分隔符切得一个空串 | 切分后过滤：`[p for p in s.split(',') if p]` |
| `','.join([1, 2])` 抛 `TypeError` | `join` 要求所有元素是 `str` | `','.join(map(str, items))` |
| `f"{d["key"]}"` 报 `SyntaxError` | 同引号嵌套，3.12 之前不支持 | 用 `f'{d["key"]}'` 或先取到变量 |
| `f"{'\n'}"` 报 `SyntaxError` | f-string 内部不能有反斜杠（3.12 之前） | 先 `nl = "\n"` 再引用 |
| `csv.reader` 处理 `'"北京,海淀"'` 时逗号被切开 | 没用 `csv` 模块，自己 `split` | `next(csv.reader(io.StringIO(line)))` |
| `dict(zip(headers, row))` 静默丢数据 | `zip` 按最短截断 | 先 `if len(row) != len(headers):` 校验 |
| `sorted(["10", "9"])` 得到 `['10', '9']` | 按字符串字符排 | `sorted(nums, key=int)` |
| 脱敏后数据再次脱敏变成一堆星号 | 函数不幂等 | 输入含 `*` 时直接返回；或先校验再脱敏 |
| `len("中文")` 返回 2 但表格对不齐 | 全角字符显示占 2 列 | 用 `unicodedata.east_asian_width` 计算显示宽度 |
| `s.encode("utf-8").decode("gbk")` 抛 `UnicodeDecodeError` | 编码解码方式不一致 | 两边用同样的编码 |

## 🧠 五、知识点速查表

### 索引与切片

```text
s[0]      第一个            s[-1]      最后一个
s[len(s)]      ❌ IndexError（最后一个是 len(s) - 1）
s.index(sub)   找子串位置（找不到抛 ValueError）
s.find(sub)    找子串位置（找不到返回 -1）

切片 s[start:stop:step]     左闭右开 [start, stop)
  s[:n]      前 n 个         s[n:]      从第 n 个到末尾
  s[::2]     隔一个取一个     s[::-1]    反转
  s[-3:]     最后三个         s[:-3]     去掉最后三个

⭐ 切片永不越界（自动钳制），索引会越界
  s[5:100] → 正常；s[100:] → ''；s[100] → IndexError
```

## 📝 六、本课小结

- **下标从 0 开始**，本质是「偏移量」。最后一个是 `len(s) - 1`，负数下标从末尾倒数。索引与 `index()` 是不同的操作。
- **切片 `s[start:stop:step]` 是左闭右开**，能省略任意参数。**切片永不越界（自动钳制），索引会越界**——这个区别让切片特别适合写「不知道边界」的通用代码。
- **`str` 不可变带来三个实际后果**：不能原地改（要用拼接或切片重建）；循环里 `+=` 是 O(n²)（要用 `join`）；必须传参的方法可以传 `0` 表示「保持原样」。
- **链式调用是安全的**，但把结果赋回原变量名会让人误判——起个新名字更清晰。
- **方法按六类记**（查 / 转 / 改 / 拆 / 判 / 编），而不是死记。`find` 返回 `-1`、`index` 抛异常、`splitlines` 处理所有换行符、`strip` 参数是字符集——这几个差异最常考。
- **f-string 嵌套引号在 3.12 前有严格限制**（PEP 701 放宽）。超过一层就把值取到变量里，这是最实用的规避方式。`=` 调试是 3.8+ 的利器。
- **CSV 必须用 `csv` 模块**，因为引号内的逗号会被 `split` 误切。`zip` 会静默截断，所以必须校验列数。
- **脱敏函数必须幂等**——输入已脱敏时原样返回。工程上应在日志封装层统一脱敏，而不是依赖每个程序员记得处理。

> **一句话总结**：字符串这一课的重点不是「背方法」，而是理解**「不可变」这个设计选择如何影响你的代码写法**，并把方法组织成「按用途分类」的知识结构。

**关键点 1：把「操作」抽象成 `(名字, 函数)` 二元组**，这样管道才能接受任意组合，包括用户自定义的：

```python
# 每个操作都是「str → str」的纯函数
OPERATIONS = {
    "strip": (lambda t: t.strip()),
    "upper": (lambda t: t.upper()),
}

def process(text: str, *operations) -> str:
    """把文本依次传给每个操作，返回最终结果。

    operations 是 (名字, 函数) 的序列。
    用元组而不是只用函数，是为了在统计报告里显示每个操作的名字。
    """
    current = text
    for name, func in operations:
        current = func(current)
    return current
```

**关键点 2：内置操作必须写成「输入字符串 → 输出字符串」的纯函数**，这是可组合的前提：

```python
def normalize_space(text: str) -> str:
    r"""把连续空白压成一个空格，并去掉首尾空白。

    ⚠️ 用正则更简洁：re.sub(r"\s+", " ", text)
       这里手写 split/join 版本是为了让人看清原理。
    """
    # split() 不传参数会自动按任意空白切分，并忽略首尾和连续空白
    return " ".join(text.split())


def remove_empty_lines(text: str) -> None:
    """删除所有空行（只有空白字符的行）。"""
    # splitlines 按各种换行符拆行
    kept = [line for line in text.splitlines() if line.strip()]
    return "\n".join(kept)


def collapse_digits(text: str) -> str:
    """把连续的数字替换成 [N]，用于脱敏手机号、订单号等。"""
    import re                                  # 标准库：正则表达式
    # r"\d+" 匹配一个或多个数字；正则的 + 表示「重复 1 次以上」
    return re.sub(r"\d+", "[N]", text)


def mask_numbers(text: str) -> str:
    """把长度 >= 6 的数字串替换成 [数字]，短数字保留（年份、分数等）。"""
    import re
    # \b 是「单词边界」，确保匹配的是完整的数字串而不是大数字的一部分
    # {6,} 表示「至少 6 位」
    return re.sub(r"\b\d{6,}\b", "[数字]", text)


def truncate(text: str, length: int = 100) -> str:
    """截断到指定长度并加省略号。"""
    if len(text) <= length:
        return text
    return text[:length] + "..."
```

**完整代码**：

```python
"""text_toolkit.py —— 挑战题：迷你文本处理引擎。

运行示例：
    python examples/quiz_L04_text_toolkit.py --demo
    python examples/quiz_L04_text_toolkit.py -i a.txt -o strip,upper,mask_numbers
只依赖标准库（argparse / re / pathlib），可直接运行。
"""

import argparse
import re
from pathlib import Path


# ============================================================
# 第 1 层：内置操作 —— 每个都是「str → str」的纯函数
# 纯函数是管道可组合的前提：无副作用、相同输入得相同输出
# ============================================================
def op_strip(text: str) -> str:
    """去首尾所有空白字符。"""
    return text.strip()


def op_normalize_space(text: str) -> str:
    """把连续空白压成一个空格，并去掉首尾空白。

    等价的正则写法：re.sub(r"\\s+", " ", text).strip()
    这里用 split/join 版本是为了让人看清原理：
    split() 不传参数时按任意空白切分，且自动忽略首尾和连续空白。
    """
    return " ".join(text.split())


def op_remove_empty_lines(text: str) -> str:
    """删除所有空行（只含空白字符的行）。"""
    # splitlines() 能识别 \\n \\r\\n \\r 等各种换行符
    kept = [line for line in text.splitlines() if line.strip()]
    return "\n".join(kept)


def op_upper(text: str) -> str:
    """转成大写。"""
    return text.upper()


def op_lower(text: str) -> str:
    """转成小写。"""
    return text.lower()


def op_collapse_digits(text: str) -> str:
    """把连续数字替换成 [N]，用于粗粒度脱敏。

    \\d+ 匹配一个或多个数字；+ 表示「重复 1 次以上」。
    """
    return re.sub(r"\d+", "[N]", text)


def op_mask_numbers(text: str) -> str:
    """把长度 >= 6 的数字串替换成 [数字]，短数字保留（年份、分数等）。

    \\b 是「单词边界」，确保匹配完整数字串而不是大数字的一部分。
    例：订单号 20260115000123 整体被替换，不会只替换后 6 位。
    """
    return re.sub(r"\b\d{6,}\b", "[数字]", text)


def op_truncate(text: str) -> str:
    """截断到 100 个字符并加省略号。"""
    limit = 100
    if len(text) <= limit:
        return text
    return text[:limit] + "..."


# 操作注册表：名字 → 函数
# 这样 CLI 解析出来的名字能直接查表得到函数
REGISTRY = {
    "strip": op_strip,
    "normalize_space": op_normalize_space,
    "remove_empty_lines": op_remove_empty_lines,
    "upper": op_upper,
    "lower": op_lower,
    "collapse_digits": op_collapse_digits,
    "mask_numbers": op_mask_numbers,
    "truncate": op_truncate,
}


# ============================================================
# 第 2 层：核心管道
# ============================================================
def process(text: str, *operations: tuple[str, object]) -> tuple[str, list[tuple[str, int, int]]]:
    """把文本依次传给每个操作，返回 (最终结果, 统计列表)。

    operations 是 (名字, 函数) 的序列。
    返回统计信息是为了让「每个操作改变了多少长度」变得可观察。
    """
    current = text
    stats: list[tuple[str, int, int]] = []
    for name, func in operations:
        before = len(current)
        current = func(current)              # 纯函数调用，无副作用
        after = len(current)
        stats.append((name, before, after))
    return current, stats


def make_ops(spec: str, custom: dict | None = None) -> list[tuple[str, object]]:
    """把逗号分隔的操作名转成 (名字, 函数) 列表。

    spec 示例："strip,upper,mask_numbers"
    custom 是用户自定义的操作，会合并进注册表（优先级更高）。
    """
    table = {**REGISTRY, **(custom or {})}
    ops: list[tuple[str, object]] = []
    for raw in spec.split(","):
        name = raw.strip()
        if not name:
            continue
        if name == "truncate":
            # truncate 需要特殊处理：它默认截断到 100，
            # 用户指定 --truncate N 时用 lambda 绑定长度
            continue                        # 由调用方单独追加
        if name not in table:
            raise ValueError(
                f"未知操作：{name}\n可用操作：{', '.join(sorted(table))}"
            )
        ops.append((name, table[name]))
    return ops

# 第 3 层：示例文本与演示
# ============================================================
SAMPLE_TEXT = """\

    张三丰  电话 13812345678  邮箱 zhangsan@example.com
    李四    电话 13900139000  邮箱 lisi@example.com

def run_demo() -> None:
    """内置演示：不依赖任何外部文件。"""
    print("=" * 72)
    print("文本处理引擎 · 内置演示")
    print("=" * 72)
    print("【原始文本】")
    print(SAMPLE_TEXT)

    demos = [
        ("组合 1：基础清洗", "strip,normalize_space,remove_empty_lines"),
        ("组合 2：清洗 + 大写", "strip,remove_empty_lines,upper"),

    for title, spec in demos:

def run_custom_demo() -> None:
    """演示自定义操作：把日期格式从 2026/01/15 转成 2026-01-15。"""
    print("\n" + "=" * 72)
    print("【自定义操作演示】")
    print("=" * 72)

    # 自定义操作就是一个 str → str 的函数
    def normalize_date(text: str) -> str:
        """把 YYYY/MM/DD 转成 YYYY-MM-DD。"""
        # re.sub 的第三个参数是替换模板，\\1 \\2 是捕获组
        return re.sub(r"(\d{4})/(\d{1,2})/(\d{1,2})",
                      r"\1-\2-\3", text)

    custom = {"normalize_date": normalize_date}
    ops = make_ops("strip,normalize_date", custom)
    text = "报表期：2026/01/15 至 2026/3/8"
    result, stats = process(text, *ops)
    print(f"输入：{text}")
    print(f"输出：{result}")
    for name, before, after in stats:
        print(f"  {name:<20}{before:>6} → {after:<6}")
    print("💡 自定义操作只要满足「str → str」就能直接接进管道")

# 第 4 层：CLI
# ============================================================
def build_parser() -> argparse.ArgumentParser:
    """构建命令行参数解析器。"""
    parser = argparse.ArgumentParser(
        description="文本处理管线工具：按操作链处理文本",
        formatter_class=argparse.RawDescriptionHelpFormatter,
        epilog="""
可用操作：
  strip              去首尾空白
  normalize_space    连续空白压成一个空格
  remove_empty_lines 删除空行
  upper / lower      大小写转换
  collapse_digits    连续数字替换成 [N]
  mask_numbers       长度>=6 的数字替换成 [数字]
  truncate           截断（配合 --truncate 指定长度）

示例：
  %(prog)s --demo
  %(prog)s -i data.txt -o strip,upper,mask_numbers
  %(prog)s -i data.txt -o strip -t 100
        """,
    )
    parser.add_argument("--input", "-i", help="输入文件路径（不指定则用内置示例）")
    parser.add_argument("--ops", "-o", default="strip,remove_empty_lines",
                        help="操作链，逗号分隔")
    parser.add_argument("--truncate", "-t", type=int, default=100,
                        help="截断长度（-o 含 truncate 时生效）")
    parser.add_argument("--demo", action="store_true", help="运行内置演示")
    parser.add_argument("--output", "-O", help="输出文件（不指定则打印到屏幕）")
    return parser


def main() -> None:
    """程序入口。"""
    args = build_parser().parse_args()

    # --demo 模式：不碰任何文件
    if args.demo:
        run_demo()
        run_custom_demo()
        return

    # 读输入：文件或内置示例
    if args.input:
        source = Path(args.input)
        if not source.exists():
            print(f"❌ 文件不存在：{source}")
            return
        # 用 utf-8 读，避免中文乱码
        text = source.read_text(encoding="utf-8")
        print(f"📄 已读取：{source}（{len(text)} 字符）")
    else:
        text = SAMPLE_TEXT
        print("📋 使用内置示例文本")

    # 组装操作链
    try:
        ops = make_ops(args.ops)
    except ValueError as exc:
        print(f"❌ {exc}")
        return
    if "truncate" in args.ops:
        ops.append((f"truncate({args.truncate})",
                    lambda t: t if len(t) <= args.truncate else t[:args.truncate] + "..."))

    # 执行管道
    result, stats = process(text, *ops)

    # 打印统计
    print(f"\n【长度变化】{len(text)} → {len(result)}")
    for name, before, after in stats:
        print(f"  {name:<20}{before:>6} → {after:<6}")

    # 输出
    if args.output:
        target = Path(args.output)
        target.write_text(result, encoding="utf-8")
        print(f"\n📄 已保存到：{target.absolute()}")
    else:
        print("\n【处理结果】")
        print(result)


if __name__ == "__main__":
    main()
```

3. 支持「逆向操作」（如 `expand_tabs`、`unsqueeze_space`），让操作可逆。
4. 加单元测试：每个操作都应该有「输入 → 期望输出」的测试用例。

</details>
