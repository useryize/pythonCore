## 📖 二、知识讲解

### 2.1 `input()`：永远返回字符串

**一句话定义**：`input()` 读取用户输入的一整行文本，**去掉末尾换行符，然后作为 `str` 返回**。

**核心事实**：

```python
# 无论用户输入什么，input() 的返回值类型都是 str
age = input("年龄：")      # 用户输入 18
print(type(age))          # <class 'str'>
print(age == 18)          # False   ⚠️ 它是 '18'，不是 18
print(age + 1)            # TypeError: can only concatenate str (not "int") to str

# 正确做法：立即转换类型
age = int(input("年龄："))
print(age + 1)            # 19  ✅
```

**为什么设计上要这样**：Python 不知道你想把输入当什么用（数字？日期？编号？），所以它只给你最通用的字符串，把「怎么解释」的决定权交给你。这是「不猜用户意图」的设计哲学。

**其他必须知道的行为**：

```python
# 1) 保留前导和尾随空格
text = input("输入（前后有空格）：")     # 用户输入 "  hi  "
print(repr(text))                       # '  hi  '  ⚠️ 空格还在
print(text.strip())                      # 'hi'     需要自己 strip

# 2) 用户直接回车 → 空字符串，不是 None
empty = input("直接回车：")
print(repr(empty))                      # ''

# 3) 输入流结束时抛 EOFError
# 在自动化测试、CI、管道输入时，如果没有内容可读，input() 直接崩
# 这就是为什么生产代码要处理 EOFError
```

⚠️ **这就是自动化运行的痛点**。如果你的脚本要能在 CI、测试、重定向场景下运行，必须包装：

```python
import sys


def safe_input(prompt: str, default: str = "") -> str:
    """包装 input()：读不到真实输入时自动返回默认值，绝不崩溃。"""
    try:
        # isatty() 返回 True 表示「连接着交互式终端」
        if not sys.stdin.isatty():
            return default
        text = input(prompt)
    except EOFError:            # 输入流被关闭时的兜底
        return default
    return text.strip() if text.strip() else default
```

### 2.2 输入转换的三大坑

**坑 1：`int()` 不接受小数点**

```python
try:
    int("3.14")
except ValueError as exc:
    print(exc)      # invalid literal for int() with base 10: '3.14'

# 需要「先取整数部分」时，要写两层转换
int(float("3.14"))  # 3

# float() 更宽松，能吃整数形式的字符串
print(float("42"))          # 42.0  ✅
print(float(" 3.14 "))       # 3.14  ✅ int/float 都会忽略首尾空白
```

**坑 2：`bool()` 的真值规则**

```python
print(bool("0"))      # True  ⚠️ 非空字符串恒为真！
print(bool("False"))  # True  ⚠️ 内容是 "False" 也是非空
print(bool(""))       # False 只有空字符串才假
```

如果你需要「把用户输入的 'False' 变成布尔值」，必须先解析：

```python
import ast
print(bool(ast.literal_eval("False")))   # False  ✅
```

**坑 3：安全转换的标准模式**

```python
# 模式 A：try/except（最通用）
def to_int(text, default=None):
    try:
        return int(text.strip())
    except ValueError:
        return default

# 模式 B：预判（多个候选值时更好）
text = "123"
if text.isdigit():
    value = int(text)
else:
    value = 0

# 模式 C：反复询问直到合法（交互式程序的正确做法）
while True:
    raw = input("请输入一个整数：").strip()
    try:
        number = int(raw)
        break                      # 合法，退出循环
    except ValueError:
        print(f"  {raw!r} 不是整数，请重新输入")
```

> 📌 **模式 C 是真实程序的写法**：不是「报错就退出」，而是「提示并重试」。给用户一次机会，比直接崩溃友好得多。

### 2.3 `print()` 的完整用法

**一句话定义**：`print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)`。

**三个关键参数**：

```python
# sep：多个参数之间的分隔符，默认一个空格
print("甲", "乙", "丙")                  # 甲 乙 丙
print("甲", "乙", "丙", sep=",")         # 甲,乙,丙
print("甲", "乙", "丙", sep="")          # 甲乙丙
print("甲", "乙", "丙", sep=" | ")       # 甲 | 乙 | 丙

# end：输出结束后追加的内容，默认换行
print("第一行", end="")                  # 没有换行
print("继续输出")                        # 输出在同一行：第一行继续输出
print("A", "B", end="; ")                # 手动指定结尾
print("C")                              # 以换行收尾

# flush：是否立即输出（不缓冲）
print("正在处理...", end="", flush=True) # 立刻显示，不等缓冲区
```

**`end=""` 的实战用途：进度条**

```python
# 进度条的效果：\r 把光标拉回行首，实现「原地刷新」
total = 5
for i in range(1, total + 1):
    print(f"\r进度 {i}/{total} {'█' * i}", end="")
print()      # 最后补一个换行收尾

# 终端实际显示（每一步都覆盖上一行）：
# 进度 1/5 █
# 进度 2/5 ██
# 进度 3/5 ███
# ...
```

**`stdout` 与 `stderr` 的区别**：

```python
import sys

print("这是正常产出")                      # → stdout
print("这是诊断信息", file=sys.stderr)     # → stderr
```

| | stdout | stderr |
| --- | --- | --- |
| 用途 | 程序的「正式产出」 | 程序的「诊断信息」 |
| 重定向 `> file` 时 | 被重定向到文件 | **仍在终端显示** |
| 管道 `\| other` 时 | 传给下一个命令 | 不参与管道 |
| 退出码 | 无 | 无（退出码用 `sys.exit()`） |

**为什么这个区分重要**：命令行工具的标准做法是「结果写 stdout，日志写 stderr」。这样 `python tool.py > result.txt` 能把干净的结果存下来，同时日志还在屏幕上可见。

### 2.4 三种字符串格式化

**一句话定义**：把「模板字符串 + 数据」组合成完整文本的三种语法方案。

#### 方式 1：f-string（Python 3.6+，**首选**）

```python
name = "张三"
age = 20
score = 87.456

# 基本用法：在 {} 里写表达式
print(f"我叫{name}，今年{age}岁，成绩{score}")

# 可以写任意表达式，包括函数调用
print(f"上课年份约 {2026 + 1}，分数四舍五入 {round(score)}")

# 调试利器：= 会自动打印「表达式=值」
n = 42
print(f"{n=}")               # n=42
print(f"{n = }")             # n = 42（注意等号两侧的空格被保留）

# 转换说明符
print(f"{name!r}")           # '张三'   repr：带引号
print(f"{name!s}")           # 张三    str：正常显示
print(f"{name!a}")           # '\u5f20\u4e09'   ascii：转义成 ASCII

# 多行 f-string，适合拼长文本
summary = f"""
    姓名：{name}
    年龄：{age}
    """
print(summary)
```

**f-string 的优点**：可读性最好、速度最快（运行时不会二次解析）、支持完整表达式、支持调试 `=`。

**f-string 的限制**：

```text
3.12 之前（PEP 701 之前）：
  - 内部不能出现反斜杠        f"{'\n'}"        → SyntaxError
  - 内部不能有 # 注释         f"{x  # 注释}"    → SyntaxError
  - 不能嵌套相同引号          f"{d["k"]}"      → SyntaxError（要外单内双）
3.12+ 全部放宽（PEP 701）
```

#### 方式 2：`%` 占位符（C 风格）

```python
name = "张三"
score = 87.456

print("我叫%s，今年%d岁，成绩%.2f" % (name, 20, score))
# %s  任何类型都接受（转成 str）
# %d  整数
# %.2f  浮点，保留 2 位小数
# %5d  整数，总宽 5，右对齐
# %-5s 字符串，总宽 5，左对齐

# %s 也能接受对象
print("列表：%s，元组：%s" % ([1, 2], (3, 4)))

# 字典格式化：用 %(key)s
d = {"name": "张三", "age": 20}
print("%(name)s 今年 %(age)d 岁" % d)      # 张三 今年 20 岁
```

**什么时候会遇到 `%`**：维护老代码、看老教程（Python 2 时代的写法是 `print "xxx"`）。**自己写新代码不要用**。

#### 方式 3：`str.format()`

```python
name = "张三"
score = 87.456

# 基本用法：{} 按位置填
print("我叫{}，成绩{}".format(name, score))

# 指定位置
print("我叫{0}，成绩{0}".format(name))     # 可重复使用

# 命名参数
print("{user} 在 {city}".format(user="李四", city="北京"))

# 格式说明符写在 {} 里
print("{:.2f}".format(score))             # 87.46
print("{:>10}|".format(name))              # 右对齐宽度 10

# 嵌套访问（.format 的优势场景之一）
d = {"user": {"name": "李四"}}
print("{user[name]}".format(user=d["user"]))   # 李四
```

**`.format()` 的优势场景**：需要**运行时动态拼接模板**时（比如模板来自数据库或配置文件）：

```python
# f-string 的变量名必须是合法标识符，无法动态
template = "{a} + {b} = {result}"
values = {"a": 1, "b": 2, "result": 3}
print(template.format(**values))          # ✅ 模板可以来自外部配置

# f-string 做不到这种动态
```

#### 三种方式怎么选

| 场景 | 选择 | 理由 |
| --- | --- | --- |
| 新写普通代码 | **f-string** | 可读性最好、最快 |
| 模板来自外部/运行时 | `.format()` | 支持动态占位符 |
| 维护老代码 | `%` | 遇到就认识，不用改 |

### 2.5 格式说明符全解

**完整语法**：

```text
[[fill]align][sign][#][0][width][,][.precision][type]

fill       填充字符，如 * - _
align      对齐：< 左（默认字符串）> 右（默认数字）^ 居中 = 两端对齐
sign       符号：+ 强制显示正号， 空格（正数前留空格，便于表格对齐）
#          进制前缀：0b 0o 0x
0          用 0 填充到指定宽度
width      最小宽度
,          千分位分隔符（也可用 _ 分组）
.precision 精度：小数点后几位（float）或最大宽度（str）
type       类型：f e d % b o x X s g n
```

**⚠️ 格式说明符必须写在冒号之后**：

```python
print(f"{3.14159:.2f}")     # ✅ 冒号后面是格式说明符
print(f"{3.14159:.2 f}")    # ❌ 冒号后面有空格 → 报 ValueError
```

**实际应用**：

```python
n = 3.14159
print(f"{n:.0f}")        # 3      四舍五入到整数（注意是 round，不是截断）
print(f"{n:.2f}")        # 3.14   保留 2 位小数
print(f"{n:8.2f}")       #     3.14   总宽 8，不足左侧补空格
print(f"{n:.5e}")        # 3.14159e+00

# 对齐
print(f"{42:<8}|")       # 42      |   左对齐
print(f"{42:>8}|")       #       42|   右对齐（数字默认）
print(f"{42:^8}|")       #   42    |   居中
print(f"{'ab':^8}|")     #   ab    |

# 填充字符
print(f"{42:*>8}|")      # *******42|
print(f"{42:-<8}|")      # 42------|   模拟账单对齐
print(f"{42:_^8}|")      # __42____|

# 千分位
big = 1234567.891
print(f"{big:,}")        # 1,234,567.891
print(f"{big:_}")        # 1_234_567.891   3.6+，可读性更好
print(f"{big:,.2f}")     # 1,234,567.89
print(f"{12345678901234567890:,}")   # 大整数也能用

# 进制
num = 255
print(f"{num:b}")        # 11111111
print(f"{num:o}")        # 377
print(f"{num:x}")        # ff
print(f"{num:X}")        # FF
print(f"{num:#x}")       # 0xff
print(f"{num:#010b}")    # 0b11111111

# 正负号（表格对齐时很有用）
print(f"{42:+d}")        # +42
print(f"{-42:+d}")       # -42
print(f"{42: d}")        #  42   非负数前留空格，负数正常（表格里正负数对齐用）
print(f"{-42: d}")       # -42

# 类型
print(f"{0.8567:.2%}")   # 85.67%   百分比
print(f"{123:d}")        # 123      转成整数字符串
```

**实战：生成对齐表格**

```python
data = [
    ("语文", 98.5),
    ("数学", 89.123),
    ("英语", 76.0),
    ("体育", 95.6789),
]
print(f"{'科目':<8}{'分数':>10}")
print("-" * 18)
for name, score in data:
    print(f"{name:<8}{score:>10.2f}")
```

输出：

```text
科目          分数
------------------
语文        98.50
数学        89.12
英语        76.00
体育        95.68
```

### 2.6 转义字符与原始字符串

**常用转义字符**：

| 转义 | 含义 | 说明 |
| --- | --- | --- |
| `\n` | 换行 | LF，`print` 用的就是这个 |
| `\t` | 水平制表符 | 对齐表格常用 |
| `\r` | 回车 | 把光标拉回行首，进度条靠它 |
| `\\` | 反斜杠 | 表示反斜杠本身 |
| `\'` `\"` | 引号 | 在字符串里输出引号 |
| `\0` | 空字符 | 几乎不用 |
| `\a` | 响铃 | 会发出提示音，几乎不用 |
| `\b` | 退格 | 光标回退一格 |
| `\f` | 换页 | 打印时换页 |
| `\xNN` | 十六进制转义 | `\x4e2d` = 中 |
| `\uNNNN` | Unicode 转义 | `\u4e2d` = 中（4 位十六进制） |
| `\UNNNNNNNN` | 完整 Unicode | `\U0001F600` = 😀（8 位） |

**⚠️ 原始字符串：路径场景必用**

```python
# ❌ 普通字符串里的 \t 是制表符、\n 是换行，路径会被吃掉
bad = "C:\temp\new\file.txt"
print(repr(bad))        # 'C:\temp\new\file.txt'  ← \t 变成了制表符！
print(bad)              # 显示为：C:<TAB>emp...
                        #          ew<换行>ile.txt
# 打印结果其实是断成两行的！

# ✅ 原始字符串让反斜杠保持字面意义
good = r"C:\temp\new\file.txt"
print(repr(good))       # 'C:\\temp\\new\\file.txt'  ← repr 显示双反斜杠
print(good)             # C:\temp\new\file.txt  ✅ 正确

# ⚠️ 但原始字符串不能以单个反斜杠结尾（那是语法错误）
# bad2 = r"C:\temp\"       # SyntaxError: raw string ends with a single backslash

# 💡 更好的做法：用 pathlib 拼路径，从根本上绕开转义问题（L23 详讲）
from pathlib import Path
p = Path("C:/temp/new") / "file.txt"    # 用 / 分隔，三平台通用
```

**多行字符串的两种写法**：

```python
# 三引号支持多行
text1 = """第一行
第二行
第三行"""

text2 = '''也支持
多行'''

# 开头加反斜杠可以吃掉第一行的换行（行连接）
text3 = """\
这是第一行
这是第二行"""
print(text3.splitlines()[0])     # '这是第一行'  ← 没有多余空行

# 引号选择：内容里有 """ 就用 '''，反之亦然
```

### 2.7 常用字符串操作

#### 去空白：`strip` 家族

```python
text = "   \t Hello Python \n  "
print(repr(text.strip()))       # 'Hello Python'   去首尾所有空白
print(repr(text.lstrip()))      # 'Hello Python \n  '  只去左边
print(repr(text.rstrip()))      # '   \t Hello Python'  只去右边

# 可以传参：只去掉指定字符集的任意组合
print(repr("xxhixx".strip("x")))        # 'hi'
print(repr("hello".strip("lo")))        # 'hel'   ⚠️ 传的是「字符集」不是「前缀后缀」
print(repr("---hello---".strip("-")))    # 'hello'
```

⚠️ **高频坑**：处理用户输入时，**先 `strip()` 再转换类型**。`int(" 42 ")` 能成功，但 `"42元"` 会失败。

#### 切分：`split` 家族

```python
# split(sep)：按分隔符切，返回列表
print("张三,18,北京".split(","))       # ['张三', '18', '北京']

# split()：不传参数时按任意空白切，且自动忽略连续空白
print("a  b\tc\nd".split())           # ['a', 'b', 'c', 'd']
print("  a b  ".split())               # ['a', 'b']  ⚠️ 两端空白被忽略

# maxsplit：最多切几刀
print("a,b,c,d".split(",", 1))         # ['a', 'b,c,d']   只切第一刀
print("a,b,c,d".rsplit(",", 1))        # ['a,b,c', 'd']   从右边切一刀

# splitlines()：按行拆（推荐处理多行文本）
print("第一行\n第二行\r\n第三行".splitlines())    # ['第一行', '第二行', '第三行']
# ⚠️ splitlines 各种换行符都认，且自动去掉换行符；用 split("\n") 可能留下 \r

# partition：只切一刀，返回三元组
print("a=b=c".partition("="))          # ('a', '=', 'b=c')
print("a=b=c".rpartition("="))         # ('a=b', '=', 'c')
# 找不到分隔符时，partition 返回 (原串, '', '')
```

⚠️ **空字符串的陷阱**：

```python
print(repr("".split(",")))     # ['']      ⚠️ 有一个空字符串，不是空列表！
print(repr("".split()))        # []        不传参时才是空列表
print(repr(",".split(",")))    # ['', '']  两个空串
print(repr("a,,b".split(","))) # ['a', '', 'b']

# 处理 CSV 前必须过滤
raw = "a, ,b"
clean = [p.strip() for p in raw.split(",") if p.strip()]
print(clean)                   # ['a', 'b']  ✅
```

#### 拼接：`join`

```python
words = ["Python", "入门", "教程"]
print(", ".join(words))         # 'Python, 入门, 教程'
print("".join(words))           # 'Python入门教程'
print("-".join(words))          # 'Python-入门-教程'
print("|".join("abc"))          # 'a|b|c'    字符串也能 join
```

⚠️ **`join` 的接收者是分隔符，操作对象是被 join 的序列**（顺序和 `split` 相反）：

```python
# split: 字符串.split(sep) → 列表
# join:  sep.join(列表)    → 字符串
#         ↑ 分隔符在前
```

⚠️ **`join` 要求所有元素都是 `str`**：

```python
try:
    ",".join(["a", 1, "b"])
except TypeError as exc:
    print(exc)      # sequence item 1: expected str instance, int found

# 解决办法
print(",".join(str(x) for x in ["a", 1, "b"]))     # 'a,1,b'
print(",".join(map(str, ["a", 1, "b"])))          # 同上，更简洁
```

#### 替换：`replace`

```python
s = "2026-01-15"
print(s.replace("-", "/"))              # '2026/01/15'
print(s.replace("-", "/", 1))           # '2026/01-15' → '2026/01-15'  只换第一处
print("a-b-c".replace("-", "+").replace("+", "="))   # 'a=b=c'  链式替换
print("aaa".replace("a", "b", 0))       # 'aaa'  count=0 表示一个都不换
```

#### 查找：`find` 家族

```python
s = "Hello, Python World"

print(s.find("Python"))      # 7      找不到返回 -1（安全）
print(s.index("Python"))     # 7      找不到抛 ValueError
print(s.find("Java"))        # -1
print(s.rfind("o"))          # 15     从右往左找
print(s.count("o"))          # 3      出现次数

print(s.startswith("Hello")) # True   前缀
print(s.endswith("World"))   # True   后缀

# find 的第二个参数可以指定起始位置
print(s.find("l", 5))        # 从下标 5 开始找第一个 l

# 找不到时的差异
try:
    s.index("Java")
except ValueError as exc:
    print(exc)               # substring not found
```

⚠️ **`find` 返回 -1，`index` 抛异常**。用 `-1` 去索引列表会导致「误判为最后一个元素」，所以查「必须存在」的东西用 `index` 更安全。

#### 大小写与判断

```python
w = "python is Fun"
print(w.upper())           # 'PYTHON IS FUN'
print(w.lower())           # 'python is fun'
print(w.capitalize())      # 'Python is fun'   只首字母大写
print(w.title())           # 'Python Is Fun'   每个单词首字母大写
print(w.swapcase())        # 'PYTHON IS fUN'   大小写互换

# 判断类：全部返回 bool
print("abc".isalpha())      # True   全是字母
print("123".isdigit())      # True   全是 0-9
print("一二三".isnumeric())  # True   还包括中文数字等（比 isdigit 范围广）
print("abc123".isalnum())   # True   字母或数字
print("   ".isspace())      # True   全是空白
print("ABC".isupper())      # True
print("Hello World".istitle())   # True
print("abc".isascii())      # True   纯 ASCII（检查英文文本很方便）
print("var_1".isidentifier())    # True   能否作变量名
```

⚠️ **`isdigit()` vs `isnumeric()`**：`"²".isdigit()` 是 `True`（Unicode 上标数字），但 `"²".isnumeric()` 也是 `True`。`isnumeric()` 范围更广（含中文数字、分数等），`isdigit()` 更严格。判断「是不是纯阿拉伯数字」用 `isdigit()` 更安全。

#### 其他常用

```python

# 编码

print("中文".encode("utf-8").decode("utf-8"))    # '中文'
# ⚠️ encode 和 decode 必须成对使用，且编码方式要一致
```

### 2.8 字符串的高频坑

**坑 1：`+=` 在循环里是 O(n²)**

```python
# ❌ 慢：每次 += 都新建一个完整字符串
s = ""
for i in range(10000):
    s += str(i)

# ✅ 快：先收集，最后一次性 join
parts = [str(i) for i in range(10000)]
s = "".join(parts)
```

**坑 2：`list +=` 和 `str +=` 行为不同**

```python
lst = [1, 2]
lst += [3]
print(lst)             # [1, 2, 3]   list 的 += 是原地追加

txt = "ab"
txt += "cd"
print(txt)             # 'abcd'      str 的 += 是新建对象再赋值
```

**坑 3：`split` 结果要考虑空输入**

```python
print(repr("".split(",")))       # ['']       ⚠️ 不是空列表
print(repr("".split()))          # []         不传参时才是空的
# 永远不要直接假定 split 的结果非空
```

## 💻 三、课堂演示代码

**关键设计**：所有 `input()` 都通过 `safe_input()` 包装，配合 `sys.stdin.isatty()` 判断，这样脚本在**有终端时正常交互、无终端（重定向/测试）时自动用默认值**，保证「能独立运行」。

```python
def safe_input(prompt: str, default: str = "") -> str:
    """包装 input()：读不到真实输入时自动返回默认值，绝不崩溃。

    为什么需要它？
        自动化测试、CI、或者把输出重定向到文件时，stdin 里没有内容，
        input() 会直接抛 EOFError 让整个脚本挂掉。脚本要「能独立运行」，
        就必须考虑这条路径。
    """
    try:
        if not sys.stdin.isatty():
            return default
        text = input(prompt)
    except EOFError:
        return default
    return text.strip() if text.strip() else default


def ask_number(prompt: str, default: float) -> float:
    """反复询问直到拿到合法数字，或用户输入为空用默认值。

    这是处理用户输入的标准模式：不是「出错就退出」，
    而是「提示并重试」——给用户一次机会比直接崩溃友好得多。
    """
    text = safe_input(prompt, default=str(default))
    try:
        return float(text)
    except ValueError:
        # ValueError 表示「字符串转 float 失败」，最常见的输入错误
        print(f"  ⚠️ {text!r} 不是数字，改用默认值 {default}")
        return default


def print_menu_table() -> None:
    """实战：用格式说明符生成对齐表格。"""
    data = [
        ("语文", 98.5),
        ("数学", 89.123),
        ("英语", 76.0),
        ("体育", 95.6789),
    ]
    # 格式说明符完整写法：{左对齐8位}{右对齐10位保留2位小数}
    print(f"{'科目':<8}{'分数':>10}")
    print("-" * 18)
    for name, score in data:
        print(f"{name:<8}{score:>10.2f}")

    # 千分位 + 百分比 + 进制
    print()
    print(f"  千分位   : {1234567.891:,.2f}")
    print(f"  下划线   : {1234567.891:_}")
    print(f"  百分比   : {0.8567:.2%}")
    print(f"  十六进制 : {255:#06x}")
    print(f"  定宽居中 : [{'居中':^10}]")
    print(f"  字符填充 : [{'填充':*<10}]")
```

## ⚠️ 四、常见错误清单

| 错误现象 | 原因 | 正确写法 |
| --- | --- | --- |
| `TypeError: can only concatenate str (not "int") to str` | `input()` 返回字符串，未转换 | `int(input(...)) + 1` |
| `ValueError: invalid literal for int() with base 10: '3.14'` | `int()` 不接受小数点 | `int(float(...))` 或直接用 `float()` |
| `EOFError` 崩溃 | 无输入可读（自动化环境） | 包装成 `safe_input`，用 `sys.stdin.isatty()` 判断 |
| `bool("False")` 是 `True` | 非空字符串都是真值 | `ast.literal_eval("False")` |
| `UnicodeEncodeError: 'gbk' codec can't encode` | Windows 终端编码不是 UTF-8 | `chcp 65001`，或用 VS Code 终端 |
| `SyntaxError: f-string: invalid syntax` 且指向 `{:.2 f}` | 冒号后有多余空格 | `{:.2f}` 格式说明符不能有空格 |
| `ValueError: Invalid format specifier` | 格式说明符写法错误 | 检查冒号后的部分，如 `{:>10.2f}` |
| 路径字符串显示断成两行 | `"\temp"` 里的 `\t` 变成了制表符 | 用原始字符串 `r"C:\temp"` |
| `SyntaxError: raw string ends with a single backslash` | 原始字符串以单个 `\` 结尾 | 去掉末尾的反斜杠，或用 `pathlib` |
| `''.split(',')` 得到 `['']` 而不是 `[]` | 空串按分隔符切得一个空串 | 切分后过滤：`[p for p in s.split(',') if p]` |
| `TypeError: expected str instance, int found` | `join` 的元素不是字符串 | `','.join(map(str, items))` |
| `IndexError` 但下标是 -1 | `find` 返回 -1 被当成合法下标 | 先判断 `if idx >= 0:` |
| `''.isdigit()` 对中文是 `False` 但你期望 `True` | `isdigit` 只认 0-9 | 用 `isnumeric()`（范围更广） |
| 循环里 `s += x` 运行很慢 | 每次都新建完整字符串 | 先收集到列表，最后 `"".join()` |
| `print` 输出中文是乱码 | 文件编码或终端编码不是 UTF-8 | 存为 UTF-8；终端 `chcp 65001` |
| `print("a", end="")` 后光标不换行 | 正是 `end=""` 的预期行为 | 需要换行时用 `print()` 或 `end="\n"` |

## 📝 六、本课小结

- **`input()` 永远返回字符串**，这是 90% 输入 bug 的根源。标准模式是「读取 → `strip()` → 转换 → 捕获 `ValueError`」。
- **`int()` 不接受小数点**，需要「取整数部分」要写 `int(float(...))`。`float()` 更宽松，会忽略首尾空白。
- **`bool("0")` 和 `bool("False")` 都是 `True`**，因为非空字符串恒为真。需要解析布尔字符串用 `ast.literal_eval()`。
- **交互程序要处理 `EOFError`**：自动化环境（CI、测试、重定向）里没有输入可读，直接调用 `input()` 会崩溃。用 `sys.stdin.isatty()` 判断是最实用的方案。
- **`print()` 的三个参数**：`sep` 控制分隔符，`end` 控制结尾（进度条靠 `end=""` + `\r`），`flush=True` 强制立即输出。
- **`stdout` 装结果，`stderr` 装日志**。这样 `python tool.py > out.txt` 能得到干净的结果，日志仍在屏幕可见。
- **三种格式化**：新代码用 **f-string**（可读性最好、最快、支持 `=` 调试）；模板来自外部时用 `.format()`；`%` 只在维护老代码时遇到。
- **格式说明符写在冒号后**：`{:>10.2f}` 表示「总宽 10、右对齐、2 位小数」。千分位用 `,` 或 `_`，百分比用 `.2%`。
- **原始字符串 `r""` 是路径场景的必需品**，否则 `\t`、`\n` 会被吃掉。更好的办法是用 `pathlib` 拼路径。
- **字符串操作要小心返回类型**：`split` 返回列表、`join` 要求全是 str、`find` 返回 -1 而 `index` 抛异常、`"".split(",")` 得到 `['']` 而不是 `[]`。

> **一句话总结**：输入输出这一课的核心不是 API，而是**「数据进入程序和离开程序时的类型与格式控制」**——进来的永远是脏数据，要清洗和转换；出去的要让人看得懂，靠格式说明符。

**关键点 1：中文宽度计算是本题的灵魂**。`len("中文")` 返回 2，但显示时占 4 列。不处理它，表格一定会错位：

```python
import unicodedata


def char_width(ch: str) -> int:
    """返回单个字符在终端里占用的列数。

    unicodedata.east_asian_width 返回：
    'W'（Wide）      → 占 2 列（中文、日文、韩文、全角标点、emoji）
    'F'（Fullwidth） → 占 2 列（全角字符）
    'A'（Ambiguous） → 通常按 1 列处理（⚠️ 有争议，见下文说明）
    'Na'（Narrow）   → 占 1 列（英文、数字、半角标点）
    """
    if unicodedata.east_asian_width(ch) in ("W", "F"):
        return 2
    return 1


def display_width(text: str) -> int:
    """返回字符串在终端里实际占用的列数（不是 len()）。"""
    return sum(char_width(ch) for ch in str(text))
```

> ⚠️ **关于 `'A'`（Ambiguous）**：这类字符（如 `·`、`°`、部分数学符号）在中文环境下某些终端按 2 列渲染，在英文终端按 1 列。**没有绝对正确的答案**，本实现选择按 1 列处理（与 `wcwidth` 库的默认行为一致），并在注释里说明这一点——这比假装不存在要专业。

**关键点 2：截断时也必须按显示宽度切**，不能直接用 `text[:n]`：

```python
def truncate(text: str, max_width: int) -> str:
    """按显示宽度截断，超出时末尾加省略号。

    ⚠️ 不能直接用 text[:max_width]，因为「中」占 2 列，
    切 3 个字符可能占了 5 列，反而超了。
    """
    if display_width(text) <= max_width:
        return text
    # 预留 1 列给省略号 '…'（它是 Ambiguous，这里按 1 列算）
    limit = max_width - 1
    result = ""
    used = 0
    for ch in str(text):
        w = char_width(ch)
        if used + w > limit:
            break
        result += ch
        used += w
    return result + "…"
```

**关键点 3：对齐填充也必须按显示宽度**，这是同一个问题的第三次出现：

```python
def pad(text: str, width: int, align: str = "l") -> str:
    """按显示宽度对齐填充（左/右/居中）。"""
    text = truncate(text, width)
    gap = width - display_width(text)
    if gap <= 0:
        return text
    if align == "r":
        return " " * gap + text
    if align == "c":
        left = gap // 2
        return " " * left + text + " " * (gap - left)
    return text + " " * gap          # 默认左对齐
```

**关键点 4：自动列宽要在截断之前算，且要预留列间距**：

```python
def compute_widths(headers, rows, max_col_width, min_col_width=4):
    """计算每列宽度：取表头和所有单元格的最大显示宽度，再做限制。"""
    widths = []
    for i, header in enumerate(headers):
        # 表头本身的宽度是下限
        col_width = display_width(header)
        for row in rows:
            if i < len(row):
                col_width = max(col_width, display_width(row[i]))
        # 限制上限，同时保证不超过 2 倍最小宽度（避免极端情况下的 0 宽）
        if max_col_width:
            col_width = min(col_width, max(max_col_width, min_col_width))
        widths.append(max(col_width, min_col_width))
    return widths
```

**完整代码**：

```python
"""table_renderer.py —— 挑战题：迷你表格渲染引擎。

运行：python examples/quiz_L03_table_renderer.py
只依赖标准库（unicodedata + pathlib），可直接运行。

核心难点：中文是全角字符，len() 返回的字符数不等于显示宽度，
不做特殊处理表格一定会错位。
"""

import unicodedata
from pathlib import Path


# ============================================================
# 第 1 层：显示宽度计算（本题的核心）
# ============================================================
def char_width(ch: str) -> int:
    """返回单个字符在终端里占用的列数。

    east_asian_width 的取值含义：
    'W'（Wide）      → 2 列：中文、日文、韩文、全角标点、部分 emoji
    'F'（Fullwidth） → 2 列：全角英数字、全角标点
    'A'（Ambiguous） → 有争议，常见做法是按 1 列
    'Na'（Narrow）   → 1 列：英文、数字、半角标点
    """
    if unicodedata.east_asian_width(ch) in ("W", "F"):
        return 2
    return 1


def display_width(text: str) -> int:
    """返回字符串在终端里实际占用的列数（不是 len()）。

    例：display_width("中文") == 4，而 len("中文") == 2
    """
    return sum(char_width(ch) for ch in str(text))


# ============================================================
# 第 2 层：截断与对齐填充
# ============================================================
def truncate(text: str, max_width: int) -> str:
    """按显示宽度截断，超出时末尾加省略号 '…'。

    ⚠️ 不能用 text[:max_width]，因为中文字符可能「半截」，
    切 N 个字符占用的显示宽度可能超过 N 列。
    """
    text = str(text)
    if display_width(text) <= max_width:
        return text
    limit = max_width - 1                 # 预留 1 列给省略号
    if limit <= 0:
        return "…"                        # 宽度太小时至少给个省略号
    result = ""
    used = 0
    for ch in text:
        w = char_width(ch)
        if used + w > limit:
            break
        result += ch
        used += w
    return result + "…"


def pad(text: str, width: int, align: str = "l") -> str:
    """按显示宽度对齐填充。align 取值：'l' 左 / 'r' 右 / 'c' 居中。"""
    text = truncate(text, width)          # 先截断到不超过 width
    gap = width - display_width(text)     # 再算出还差几列
    if gap <= 0:
        return text
    if align == "r":
        return " " * gap + text
    if align == "c":
        left = gap // 2
        return " " * left + text + " " * (gap - left)
    return text + " " * gap               # 默认左对齐


def auto_align(value: object) -> str:
    """自动判断对齐方式：数字右对齐，其余左对齐。

    数字右对齐是小数点对齐的视觉惯例（1.5 / 20.0 / 3.14 竖着看小数点一致）。
    """
    return "r" if isinstance(value, (int, float)) and not isinstance(value, bool) else "l"


# ============================================================
# 第 3 层：列宽计算
# ============================================================
def compute_widths(headers: list, rows: list, max_col_width: int | None,
                   min_col_width: int = 4, col_gap: int = 2) -> list[int]:
    """计算每列的显示宽度。

    规则：
      1. 至少等于表头宽度
      2. 至少等于该列所有单元格的最大宽度
      3. 若给了 max_col_width，超过则截断到上限（但不低于最小宽度）
    """
    widths = []
    for i, header in enumerate(headers):
        # 从表头宽度起算
        col_width = display_width(header)
        # 和这一列的所有单元格比较取最大值
        for row in rows:
            if i < len(row):              # 防御：数据列数可能不齐
                col_width = max(col_width, display_width(row[i]))
        if max_col_width:
            # 上限和最小宽度取较大值，避免列被压成 0 宽
            col_width = min(col_width, max(max_col_width, min_col_width))
        widths.append(max(col_width, min_col_width))
    return widths


# ============================================================
# 第 4 层：主渲染函数
# ============================================================
def render_table(headers: list, rows: list, aligns: list | None = None,
                 title: str | None = None, max_col_width: int | None = None,
                 col_gap: int = 2, caption: str | None = None) -> str:
    """渲染一张对齐的表格，返回渲染后的完整字符串。

    参数：
        headers        表头列表
        rows           数据行（二维列表）
        aligns         每列对齐方式 ['l'/'r'/'c']，None 表示自动判断
        title          表格标题（居中显示在顶部）
        max_col_width  每列最大显示宽度，超出截断
        col_gap        列间距（空格数）
        caption        表格下方的说明文字
    """
    lines: list[str] = []

    # ---- 处理空表 ----
    if not headers:
        return "（无表头）\n"

    # ---- 计算对齐方式 ----
    if aligns is None:
        # 自动判断：看第一行数据的类型（没有数据就看表头）
        sample_row = rows[0] if rows else headers
        aligns = [auto_align(v) for v in sample_row]
    # 补齐 / 截断 aligns 长度，保证和表头一致
    aligns = (list(aligns) + ["l"] * len(headers))[:len(headers)]

    # ---- 计算列宽 ----
    widths = compute_widths(headers, rows, max_col_width)
    sep = " " * col_gap                   # 列间隔

    # ---- 标题 ----
    total_width = sum(widths) + col_gap * (len(widths) - 1)
    if title:
        # 标题居中：用 display_width 计算才能真正居中
        gap = (total_width - display_width(title)) // 2
        lines.append(" " * max(gap, 0) + str(title))
        lines.append("=" * total_width)

    # ---- 空数据处理 ----
    if not rows:
        lines.append("（无数据）")
        return "\n".join(lines) + "\n"

    # ---- 表头 ----
    header_line = sep.join(
        pad(headers[i], widths[i], "c")     # 表头统一居中，更好看
        for i in range(len(headers))
    )
    lines.append(header_line)
    # ---- 分隔线 ----
    lines.append("-" * total_width)

    # ---- 数据行 ----
    for row in rows:
        cells = []
        for i in range(len(headers)):
            value = row[i] if i < len(row) else ""     # 列数不齐时补空
            cells.append(pad(value, widths[i], aligns[i]))
        lines.append(sep.join(cells))

    # ---- 表格说明 ----
    if caption:
        lines.append(caption)

    return "\n".join(lines) + "\n"
```
