## 📖 二、知识讲解

### 2.1 变量到底是什么：标签模型

**一句话定义**：变量是一个**指向某个对象的名称**，赋值语句做的事是「让这个名字指向某个对象」，而不是「往盒子里装东西」。

**为什么必须先搞清楚这个**：几乎所有初学者对 Python 的误解都源于把变量想成盒子。理解成标签之后，很多现象会瞬间变得自然：

- 为什么两个变量可以指向同一个对象？
- 为什么改了 `b` 之后 `a` 也会变（针对列表）？
- 为什么字符串「改不了」？
- 为什么 `is` 会得到 `True` 或 `False`？

**可运行的最小示例**：

```python
# 第 1 步：创建一个 int 对象 42，让名字 first 指向它
first = 42
# 第 2 步：让名字 second 也指向同一个对象（不是复制一份！）
second = first
# 第 3 步：让 first 改指向另一个对象 100
first = 100
# 第 4 步：观察 second —— 它还指着原来那个 42
print(first)    # 100
print(second)   # 42

# 用 id() 证明「两个标签可以贴同一个对象」
a = 42
b = 42
print(id(a) == id(b))   # True，因为小整数 42 被 Python 缓存复用了

# 用 is 判断身份
print(a is b)           # True：同一个对象
print(a == b)           # True：值相等
```

⚠️ **注意第三步的语义**：`first = 100` 并没有「修改 first 指向的对象」，因为 `42` 是不可变的。它只是让 `first` 这个标签**撕下来贴到了另一个对象上**。

**常见用法与边界情况**：

| 场景 | 说明 |
| --- | --- |
| 赋值 | `x = 5` —— 创建（或复用）对象，让 x 指向它 |
| 重新赋值 | `x = 10` —— x 改指向新对象，旧对象若无其他引用则被回收 |
| 多名同指 | `a = b = []` —— 两个名字指向**同一个空列表**（⚠️ 高频坑） |
| 常量约定 | `MAX_SIZE = 100` —— Python 无真正的常量，靠命名约定 |

**⚠️ 初学者最容易踩的坑**：

```python
# ❌ 坑：以为 a 和 b 是两个独立的列表
a = []
b = a              # 复制的是「标签」，不是「内容」
b.append(1)
print(a)            # [1]  ← a 也变了！

# ✅ 正确：需要独立副本时显式拷贝
a = []
b = a.copy()       # 或者 list(a)、a[:]
b.append(1)
print(a)            # []  ← 互不影响
```

### 2.2 动态类型：类型属于对象，不属于变量

**一句话定义**：Python 在**运行期**才确定一个值的类型；变量名可以在不同时刻指向不同类型的对象。

**为什么需要它**：省掉了 `int x;` / `String s;` 这类声明，行数直接减少，也让「先写逻辑、后定类型」成为可能。

**可运行的最小示例**：

```python
value = 100                  # 此刻是 int
print(type(value))           # <class 'int'>

value = "一百"                # 换成 str，Python 完全允许
print(type(value))           # <class 'str'>

value = [1, 2, 3]             # 还能换成 list
print(type(value))           # <class 'list'>
```

**动态类型的两面性**：

| 好处 | 代价 |
| --- | --- |
| 代码行数少，入门快 | 类型错误在**运行时**才暴露，不是编译时 |
| 不用维护大量类型声明 | 变量被复用于不同类型，可读性下降 |
| 同一段逻辑能处理多种类型（L04 的多态基础） | 大型项目里缺乏编译期保护，需要靠测试和类型标注补足 |

**常见用法与边界情况**：

- Python 3.5+ 支持**类型标注**：`x: int = 5`。它不改变运行行为，作用是给编辑器和静态检查工具提供信息。
- 团队项目推荐逐步加类型标注，个人小脚本可以不加。

⚠️ **坑**：不要用「换一个类型」来表达「这个变量不用了」。正确做法是设成 `None`，它语义明确：

```python
# ❌ 用魔法值表示「没值」，读者一头雾水
result = 0          # 到底是「结果是 0」还是「还没算」？

# ✅ 用 None，语义清晰
result = None       # 明确表示「还没有结果」
```

### 2.3 五种基础类型逐个击破

#### 2.3.1 int（整数）：任意精度，不会溢出

**一句话定义**：整数类型，能表示任意大小的整数，没有 64 位上限。

**为什么需要知道「任意精度」**：Java 的 `long` 最大约 9.2×10¹⁸，超过就溢出；Python 不会，你可以直接算 2 的 1000 次方。

```python
big = 2 ** 100
print(big)                 # 1267650600228229401496703205376
print(big.bit_length())    # 101（二进制位数）

# 下划线只是视觉分隔符，不影响数值
million = 1_000_000        # 等价于 1000000，但一眼看出是百万
print(f"{million:,}")      # 1,000,000

# ⚠️ 关于「千分位」：它只是显示格式，值仍然是 1000000
print(million == 1000000)  # True
```

**取模与除法**（后面 L06 会大量用到）：

```python
print(17 // 5)   # 3   地板除法，向下取整
print(17 / 5)    # 3.4 真除法，永远返回 float
print(17 % 5)    # 2   取余

# 恒等式：a == b * (a // b) + a % b
# 这个恒等式对负数也成立，这是 Python 取余设计的巧妙之处
print(-17 // 5)  # -4  （向下取整，不是「向零截断」）
print(-17 % 5)   # 3   （余数符号跟随除数，保证恒等式成立）
```

⚠️ **坑**：如果你的业务逻辑期望「向零截断」（比如财务里的「去掉小数部分」），Python 的 `//` 不符合预期，需要用 `math.trunc()` 或 `int()`。

#### 2.3.2 float（浮点数）：能表示小数，但不能表示「精确」

**一句话定义**：双精度浮点数，约 15~17 位有效数字，用科学计数法存储。

**核心认知：float 是「近似值」，不是「精确十进制」**。

```python
print(0.1 + 0.2)          # 0.30000000000000004  ← 不是 0.3！
print(0.1 + 0.2 == 0.3)   # False

# 为什么？因为 0.1 在二进制里是无限循环小数，就像十进制无法精确表示 1/3
# 1/3 = 0.333333... 无限循环
# 1/10 用二进制表示也是 0.001100110011... 无限循环
# 存储时只能截断到 16 位，所以有了误差
```

**float 能表示的范围**：

| 项 | 值 |
| --- | --- |
| 最大值 | 约 1.7976931348623157e+308 |
| 最小正数 | 约 5e-324 |
| 有效数字 | 约 15~17 位（通常认为是 15 位可靠） |

**⚠️ 三种应对浮点误差的方案**：

```python
# 方案 A：比较时用容差（最常用）
import math
print(math.isclose(0.1 + 0.2, 0.3))          # True

# 或者手写容差
print(abs((0.1 + 0.2) - 0.3) < 1e-9)          # True

# 方案 B：金额用整数存「分」，用时才除（财务场景首选）
price_cents = 1999                            # 存 1999 分
print(f"{price_cents / 100:.2f} 元")            # 19.99 元

# 方案 C：确实需要精确十进制时用 decimal 模块（标准库，无需 pip）
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))        # 0.3  ✅ 精确

# ⚠️ Decimal 的关键陷阱：必须用字符串初始化
print(Decimal(0.1) + Decimal(0.2))            # 0.30000000000000004 ❌ 错误示范
# 因为 float(0.1) 本身已经带着误差，传进去等于「把误差固化」
```

⚠️ **坑 2：科学计数法与位数丢失**。超过 15 位有效数字的数字，float 已经记不住了：

```python
big_id = 123456789012345678901234567890.0
print(f"{big_id:.0f}")     # 123456789012345677877719597056  ← 后半段全是噪声
print(f"{big_id:.0f}" == "123456789012345678901234567890")   # False

# 需要精确的大整数 → 用 int，它不会丢
print(123456789012345678901234567890)           # 123456789012345678901234567890 ✅
```

#### 2.3.3 str（字符串）：不可变的 Unicode 序列

**一句话定义**：字符串是一串字符的序列，**创建后不能修改**，任何「修改」都返回新对象。

```python
s = "Python"
print(s[0])       # 'P'   第一个字符
print(s[-1])      # 'n'   最后一个字符
print(s[1:4])     # 'yth' 切片，[1,4) 左闭右开
print(s[::-1])    # 'nohtyP' 反转
print(len(s))     # 6

# 单引号和双引号完全等价，选哪个只取决于「里面有没有那个引号」
a = "他说：'你好'"
b = '他说："你好"'

# 不可变的直接体现
s_upper = s.upper()     # 返回新对象
print(s)                # 'Python' —— 原串没变
```

**为什么字符串要设计成不可变**：安全性和哈希。不可变对象可以安全地作为字典的键、被多处同时引用而不用担心被偷偷改掉。L08 讲字典时会看到这一点带来的好处。

⚠️ **坑**：循环里 `s += x` 是 O(n²)。正确做法：

```python
# ❌ 每次 += 都新建一个完整的字符串，10 万次要复制 10 万遍
result = ""
for ch in text:
    result += ch

# ✅ 先收集到列表，最后一次性拼接
result = "".join(list(text))
```

#### 2.3.4 bool（布尔值）：只有两个值，但能算术

**一句话定义**：布尔类型只有 `True` 和 `False`，它们是 `int` 的子类，数值上等于 1 和 0。

```python
print(type(True))          # <class 'bool'>
print(True + True)          # 2      ← 印证了 bool 是 int 的子类
print(isinstance(True, int))# True

# 取反
print(not True)             # False

# ⚠️ 真值判断的完整清单（Falsy 值共 10 种）
falsy = [False, None, 0, 0.0, 0j, "", [], {}, set(), ()]
for v in falsy:
    print(f"bool({v!r}) = {bool(v)}")
```

⚠️ **坑 1：`bool` 参与算术时容易造成逻辑错误**：

```python
is_vip = True
price = 100.0

# ❌ 直觉上「VIP 应该有折扣」，但这里算出的是 90！因为 True 变成了 1 被减掉了
price_wrong = price - is_vip * 10

# ✅ 用逻辑取反来表达「非会员才扣钱」
price_right = price - (not is_vip) * 10    # 100.0
```

⚠️ **坑 2：`False` 和 `None` 不相等，但真值上等价**：

```python
print(None == False)        # False   ← 值不相等
print(bool(None) == bool(False))  # True  ← 真值判断上等价
print(None is False)        # False   ← 身份也不同

# 三者关系：值不相等、身份不同、真值等价
# 实用结论：判断「有没有值」用 None，判断「是不是假」用 False
```

#### 2.3.5 NoneType（空值）：表示「这里没有东西」

**一句话定义**：`None` 是「空」的表示，类型是 `NoneType`，是**唯一一个合法单例**。

```python
print(type(None))           # <class 'NoneType'>
print(None is None)         # True    永远成立（单例）
print(None == None)         # True

# None 参与运算会报错
try:
    print(None + 1)
except TypeError as e:
    print(e)                # unsupported operand type(s) for +: 'NoneType' and 'int'

# 必须先判断再使用
value = None
if value is not None:       # ✅ 正确写法
    print(value + 1)
```

⚠️ **坑**：`is None` 不能写成 `== None`（虽然现在能工作，但 `==` 允许子类重载，语义不严格）；更不能写成 `not value`（因为 `0`、`""`、`[]` 都是 falsy）。

### 2.4 `type()` 与 `isinstance()`：如何检查类型

**一句话定义**：`type(x)` 返回「x 到底是什么类型」；`isinstance(x, T)` 返回「x 是不是 T 或 T 的子类」。

**核心差异**：

| | `type(x) == T` | `isinstance(x, T)` |
| --- | --- | --- |
| 对子类 | 返回 `False` | 返回 `True` |
| 能否一次判多个类型 | 不能 | 能：`isinstance(x, (int, float))` |
| 适用场景 | 需要「精确是这一种类型」 | 需要「属于这一类类型」 |

**可运行的最小示例**：

```python
data = [1, 2.0, "3", True, None, [1], (1,), {"k": 1}, {1, 2}]
for d in data:
    print(f"{str(d):<10} type={type(d).__name__:<10} "
          f"is_int={isinstance(d, int):<6} is_num={isinstance(d, (int, float))}")
```

**⚠️ 高频陷阱：`bool` 是 `int` 的子类**：

```python
print(isinstance(True, int))      # True  ← 因为 bool 继承自 int
print(type(True) == int)          # False ← type 精确比较是正确的

# 如果你只想要「纯粹的整数」，必须显式排除 bool
def is_pure_int(x):
    return isinstance(x, int) and not isinstance(x, bool)

print(is_pure_int(10))            # True
print(is_pure_int(True))          # False ← 排除了 bool

# 实用技巧：直接问「它是不是那个确切的类型」
print(type(2.0) is float)          # True
```

**💡 实践建议**：写业务代码时，90% 的情况应该用 `isinstance`，因为它更宽松也更符合「判断归属」的直觉。只有在「必须确认类型完全一致」时（比如做序列化分发、或者要排除 bool）才用 `type()`。

### 2.5 可变 vs 不可变

**一句话定义**：可变对象（list、dict、set）创建后可以原地修改内容；不可变对象（int、float、str、tuple、bytes）一旦创建，其值永远不变。

**为什么必须分清**：它决定了「赋值」到底是复制内容还是复制引用。

| 类型 | 可变性 | 说明 |
| --- | --- | --- |
| `int` `float` `bool` `None` | 不可变 | 数值运算都是「产生新值」 |
| `str` | 不可变 | 所有「修改」方法都返回新字符串 |
| `bytes` | 不可变 | 同 str |
| `tuple` | 不可变 | L08 详讲 |
| `list` | **可变** | `append`、`extend`、索引赋值都原地改 |
| `set` | **可变** | `add`、`remove` 原地改 |
| `dict` | **可变** | `update`、`[key] =` 原地改 |

**可运行的最小示例**：

```python
# 不可变：赋值只是换了标签
s = "hello"
s_upper = s.upper()
print(s, s_upper)            # hello HELLO   原串没动

# 可变：赋值共享同一个对象
items = ["a", "b"]
alias = items
alias.append("c")
print(items)                  # ['a', 'b', 'c']  ← 都变了

# 需要副本时显式拷贝
copy = items.copy()
copy.append("d")
print(items, copy)            # ['a','b','c'] ['a','b','c','d']

# 嵌套结构时浅拷贝不够
nested = [[1, 2], [3, 4]]
shallow = nested.copy()       # 浅拷贝：外层新，内层还是同一批列表
shallow[0][0] = 99
print(nested)                 # [[99, 2], [3, 4]]  ← 内层被改了！

# 深拷贝要逐层重建
deep = [[row[:] for row in nested]]
deep[0][0] = 0
print(nested, deep)           # [[99,2],[3,4]]  [[0,2],[3,4]]  ✅ 互不影响
```

⚠️ **坑**：`copy()` 是**浅拷贝**，只复制一层。嵌套结构必须用 `copy.deepcopy()`（标准库，L08 详讲）。

### 2.6 类型转换

**一句话定义**：四个转换函数把一种类型的值转成另一种；`int()` 和 `float()` 在转换失败时抛 `ValueError`。

```python
# int()：字符串数字 → 整数
print(int("42"))             # 42
print(int("  7  "))          # 7    自动忽略首尾空白
print(int(3.9))              # 3    ⚠️ 直接截断，不是四舍五入！
print(round(3.9, 0))         # 4.0  四舍五入得到浮点

# ⚠️ int() 不接受带小数点的字符串（超高频报错）
try:
    int("3.14")
except ValueError as e:
    print(e)                 # invalid literal for int() with base 10: '3.14'

# float()：更宽松
print(float("3.14"))         # 3.14
print(float("42"))           # 42.0  整数串也能转
try:
    float("abc")
except ValueError as e:
    print(e)                 # could not convert string to float: 'abc'

# str()：几乎什么都能转
print(str(42), str(3.14), str(None), str([1, 2]))

# bool()：遵循真值规则
print(bool(0), bool("0"), bool(""), bool(" "))
#       False   True      False   True    ← ⚠️ 非空字符串都是 True
```

**⚠️ 安全转换模式**（处理用户输入必备）：

```python
# 模式 A：try/except，失败返回 None 或默认值
def safe_int(text):
    try:
        return int(text.strip())
    except ValueError:
        return None

print(safe_int(" 42 "))       # 42
print(safe_int("4.2"))        # None ← 小数不能转 int
print(safe_int("abc"))        # None

# 模式 B：先预判再转（多个可选值时更好）
text = "123"
if text.isdigit():
    value = int(text)
else:
    value = 0

# 模式 C：要求严格是整数格式（允许负号）
import re
def is_int(s):
    return bool(re.fullmatch(r"[+-]?\d+", s.strip()))
print(is_int("-42"))          # True
print(is_int("4.2"))          # False
```

⚠️ **坑 1**：`int("3.14")` 报错。想「先取整数部分」应该写 `int(float("3.14"))`。

⚠️ **坑 2**：`bool("False")` 是 `True`。如果你要「把字符串 'False' 转成布尔值」，必须先转成真布尔值再转换：

```python
# ❌ 不符合直觉
print(bool("False"))         # True

# ✅ 符合直觉：把字符串当表达式解析
import ast
print(bool(ast.literal_eval("False")))   # False
```

### 2.7 变量命名规范

**规则**（违反会直接报错）：

| 规则 | 合法示例 | 非法示例及原因 |
| --- | --- | --- |
| 只能含字母、数字、下划线，且不以数字开头 | `user_1` | `1user` → 以数字开头 |

### 2.8 三大高频坑深度剖析

#### 坑 1：字符串数字「相加」

**现象**：`input()` 拿到的永远是字符串，两个字符串用 `+` 是拼接。

```python
age = input("年龄：")      # 用户输入 "18"
print(age + 1)             # ❌ TypeError: can only concatenate str (not "int") to str

# ✅ 正确：先转类型
print(int(age) + 1)        # 19
```

⚠️ **更隐蔽的版本**：两个都转换了，但有一个漏转：

```python
price = "19.9"             # 忘了转
quantity = 3               # 已经是 int
print(price * quantity)    # ⚠️ 不是 59.7，而是 "19.919.919.9"（字符串重复 3 次！）
```

⚠️ **`*` 在字符串上的语义**：字符串乘整数是「重复」，这是设计给文本构造用的（`"-" * 50`），但极易和「数值乘法」混淆。

#### 坑 2：float 精度

**根因**：十进制小数在二进制里通常是无限循环小数，无法精确表示，只能截断。

**验证**：

```python
print(0.1 + 0.2)                   # 0.30000000000000004
print(f"{0.1 + 0.2:.17f}")          # 0.30000000000000004  ← 看到真实误差
print(abs(0.1 + 0.2 - 0.3))         # 5.551115123125783e-17 ← 误差极小但不为 0
```

**不要用这个「解决方案」**：

```python
# ❌ 危险：用 round 掩盖问题
if round(0.1 + 0.2, 10) == 0.3:     # 能工作，但 round 的位数选择本身是拍脑袋的
    ...
# 真正的原则是：不要用等号比较浮点数
```

**正确的判断方式**：

```python
import math
# math.isclose 是标准库方案，默认 rel_tol=1e-9
if math.isclose(a, b):
    ...

# 手写容差（理解原理时用）
if abs(a - b) < 1e-9:
    ...

# 范围判断（最简洁，且天然规避问题）
if 0.299999 < a < 0.300001:
    ...
```

**金融场景的根本解法**：

```python
# 用整数存最小单位（分/厘），彻底避免浮点
total_cents = 1990 + 2099            # 精确的整数加法
print(total_cents / 100)             # 40.89  只在「展示」时才除
# 或者用 Decimal
from decimal import Decimal
total = Decimal("19.90") + Decimal("20.99")
print(total)                          # 40.89  ✅ 全程精确
```

#### 坑 3：bool 参与运算

**根因**：`True == 1`、`False == 0`，Python 不会阻止你把它们当数字用。

**四种典型翻车**：

```python
# 翻车 1：折扣方向反了
is_vip = True
print(100 - is_vip * 10)              # 90  ← VIP 反而更便宜！

# 翻车 2：用 and/or 当三元
has_permission = False
is_admin = False
level = "admin" if has_permission and is_admin else "user"
# 如果想表达「admin 或权限任一满足」，必须写 (a or b)

# 翻车 3：统计时忘记转换
results = [True, False, True]
count = sum(results)                  # 2  ← 恰好对，但读者一脸问号
# 更清晰的写法
count = sum(1 for r in results if r)  # 明确表达「计数」

# 翻车 4：字符串 "False" 的转换
user_input = "False"
print(bool(user_input))               # True ← 完全不符合直觉！
```

**判断 bool 是否参与算术的经验法则**：如果你在表达式里看到 `True * x` 或 `False + x`，99% 是写错了。**布尔值应该只出现在 `if` 条件里**。

## ⚠️ 四、常见错误清单

| 错误现象 | 原因 | 正确写法 |
| --- | --- | --- |
| `TypeError: can only concatenate str (not "int") to str` | `input()` 返回字符串，没转换就参与加法 | `age = int(input("年龄："))` |
| `TypeError: can only multiply sequence by non-int of type 'str'` | 对字符串用了 `*` 数字 | 先 `int()` 再乘 |
| `0.1 + 0.2 == 0.3` 返回 `False` | float 用二进制存储，无法精确表示十进制小数 | `abs(a - b) < 1e-9` 或 `math.isclose()` |
| `round(2.5) == 2` 不是 3 | Python 的 `round()` 是「银行家舍入」（四舍六入五成双） | 需要普通四舍五入写 `math.floor(x + 0.5)` |
| `round(0.1 + 0.2, 2) == 0.3` 为 `False` | 截断后的 0.3 与字面量 0.3 的二进制表示仍不同 | 用 `math.isclose()`，或 `f"{x:.2f}"` 只用于显示 |
| `int("3.14")` 抛 `ValueError` | `int()` 不接受小数点 | `int(float("3.14"))` 或直接用 `float()` |
| `bool("False")` 返回 `True` | 非空字符串都是真值 | `ast.literal_eval("False")` 或先转再判 |
| `isinstance(True, int)` 返回 `True` | bool 是 int 的子类 | `isinstance(x, int) and not isinstance(x, bool)` |
| 改动 `b` 后 `a` 也变了（列表） | 赋值复制的是引用，不是内容 | `b = a.copy()` 或 `a[:]` |
| 嵌套列表浅拷贝后内层被改 | `copy()` 只复制一层 | `copy.deepcopy()` 或嵌套推导式重建 |
| `NameError: name 'lst' is not defined` | 累加器忘了初始化，或变量名拼错 | 循环前先 `total = 0` |
| 用 `list` / `dict` / `sum` 作为变量名后报 `not callable` | 覆盖了内置函数 | 换个名字，如 `items`、`total` |
| `IndentationError: unexpected indent` | 缩进不一致（混用 Tab 和空格） | 全程用 4 空格，编辑器设为 Tab 转空格 |
| `SyntaxError: invalid character '，'` | 中文标点混入代码（用了全角逗号 `，`） | 代码里必须是半角符号 `,` `:` `(` |
| `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'` | 对 `None` 直接做了算术 | 先 `if x is not None:` |

## 📝 六、本课小结

- **变量是贴在对象上的标签，不是盒子**。这个模型能解释「为什么改 b 会影响 a」「为什么字符串改不了」「为什么 is 会时真时假」等一系列现象。用 `id()` 和 `is` 可以亲手验证它。
- **Python 是动态类型**：类型属于对象而非变量，同一个名字可以先后指向不同类型的对象。好处是灵活，代价是类型错误推迟到运行时才暴露。
- **五种基础类型**：int 任意精度不会溢出；float 有精度误差，比较要用容差；str 不可变，所有「修改」返回新对象；bool 只有两值但是 int 子类，可参与算术（这是坑）；None 是唯一单例，表示「没有值」。
- **`type()` vs `isinstance()`**：前者精确匹配类型，后者判断「是否属于这一类」（含子类）。业务代码 90% 应该用 `isinstance`。注意 `bool` 是 `int` 的子类。
- **可变与不可变决定赋值语义**：不可变对象赋值是「新标签」，可变对象赋值是「共享引用」。需要副本时必须显式 `copy()`，嵌套结构要用 `deepcopy()`。
- **类型转换要处理失败**：`int("3.14")` 会抛 `ValueError`。处理用户输入的标准模式是 `try/except` + 返回默认值，或先用 `isdigit()` 预判。
- **三大坑要形成肌肉记忆**：字符串数字相加（`input()` 恒返回 str）、float 用 `==` 比较（改用容差或 Decimal）、bool 参与算术（布尔只应出现在 `if` 条件里）。
- **命名遵循 PEP 8**：变量 `snake_case`，常量 `UPPER_CASE`，布尔加 `is_`/`has_` 前缀。绝不要用关键字或内置函数名当变量名。

> **一句话总结**：变量这章的重点不是「有几个类型」，而是**建立「标签」心智模型**，并对「动态类型带来的便利」和「类型不匹配带来的坑」保持清醒。

**关键点 1：用「实际尝试修改」来判断可变性，而不是查表**。这是本题最有价值的部分——它把「不可变」从一个需要背诵的规则，变成了一个可验证的事实：

```python
def check_mutable(obj: object) -> bool:
    """通过实际尝试修改来判断对象是否可变。

    可变对象：修改成功（内存内容变了）
    不可变对象：修改会抛出异常（因为它只能产生新对象）
    """
    # 只对已知的「容器和数值」类型做测试，未知类型保守判定为不可变
    try:
        if isinstance(obj, list):
            obj.append(0)                 # 尝试原地追加
        elif isinstance(obj, dict):
            obj["__probe__"] = 0           # 尝试原地新增键
        elif isinstance(obj, set):
            obj.add(0)                     # 尝试原地新增元素
        elif isinstance(obj, bytearray):
            obj.append(0)
        elif isinstance(obj, int):
            obj += 1                      # ⚠️ 这不改原对象，int 不可变
            # int += 1 成功但不改变原对象，所以要用别的方式判断
            raise TypeError("int 不可变")
        else:
            return False                   # str/tuple/float 等：不可变
    except TypeError:
        return False                       # 修改被拒绝 → 不可变
    return True                            # 修改成功 → 可变
```

> ⚠️ 上面 `int` 分支的写法有点绕。更清晰的做法是**只对容器类型做测试**，不可变类型直接返回 `False`：

```python
def check_mutable(obj: object) -> bool:
    """更清晰的可变性判定：只测试容器类型能否原地修改。"""
    try:
        if isinstance(obj, list):
            original_len = len(obj)
            obj.append("__probe__")
            grew = len(obj) > original_len
            obj.pop()                      # 恢复原状，不污染数据
            return grew
        if isinstance(obj, dict):
            obj["__probe__"] = 0
            del obj["__probe__"]
            return True
        if isinstance(obj, set):
            obj.add("__probe__")
            obj.discard("__probe__")
            return True
        if isinstance(obj, bytearray):
            original_len = len(obj)
            obj.append(0)
            grew = len(obj) > original_len
            del obj[original_len:]
            return True
    except (AttributeError, TypeError):
        return False
    return False                            # 数字、字符串、元组 → 不可变
```

**关键点 2：元素类型分布用 `Counter`，比手写 dict 累加快得多**：

```python
from collections import Counter


def type_distribution(container: object) -> dict[str, int]:
    """统计容器内各元素的类型分布。"""
    values = list(container.values()) if isinstance(container, dict) else list(container)
    # 用 type(x).__name__ 作为 key，Counter 自动累加计数
    return dict(Counter(type(v).__name__ for v in values))
```

**关键点 3：生成建议时用「数据类型 → 建议」的映射表，保持代码整洁**：

```python
# 建议规则表：key 是判断条件，value 是建议文案
ADVICE_RULES = [
    (lambda o: isinstance(o, float),      "float 存在精度误差，金额场景建议改用 Decimal 或整数分"),
    (lambda o: isinstance(o, list) and not o, "空列表无法区分「没有数据」和「数据是空」，建议用 None 占位"),
    (lambda o: isinstance(o, dict) and not o, "空字典同上，建议区分「无配置」与「配置为空」"),
    (lambda o: o is None,                  "None 是合理的空值，但使用前务必先判空"),
    (lambda o: isinstance(o, str) and not o.strip(), "全空白字符串建议 strip() 后再判断"),
    (lambda o: isinstance(o, (int, float)) and o == 0, "零值合法，但注意它与 None 的语义区别"),
]


def suggest(obj: object) -> list[str]:
    """根据类型给出针对性建议。"""
    result = []
    for condition, text in ADVICE_RULES:
        if condition(obj):                  # 命中规则就收集建议
            result.append(text)
    if not result:
        result.append("✅ 未发现常见问题，可放心使用")
    return result
```

**完整代码**：

```python
"""type_doctor.py —— 挑战题：类型体检工具。

运行：python examples/quiz_L01_type_doctor.py
只依赖标准库，可直接运行。
"""

import sys
from collections import Counter


# ============================================================
# 可变性检测：实际尝试修改，而不是查表
# ============================================================
def check_mutable(obj: object) -> bool:
    """通过实际修改测试来判断对象是否可变（测试后会恢复原状）。"""
    try:
        if isinstance(obj, list):
            original_len = len(obj)
            obj.append("__probe__")        # 尝试原地追加
            grew = len(obj) > original_len
            obj.pop()                       # 立刻恢复，不污染原数据
            return grew
        if isinstance(obj, dict):
            obj["__probe__"] = 0            # 尝试原地新增键
            del obj["__probe__"]
            return True
        if isinstance(obj, set):
            obj.add("__probe__")
            obj.discard("__probe__")
            return True
        if isinstance(obj, bytearray):
            original_len = len(obj)
            obj.append(0)
            grew = len(obj) > original_len
            del obj[original_len:]
            return True
    except (AttributeError, TypeError):
        return False
    return False                             # 数字 / 字符串 / 元组 → 不可变


# ============================================================
# 容器信息提取
# ============================================================
def type_distribution(container: object) -> dict[str, int]:
    """统计容器内各元素的类型分布（字典统计键，其他统计元素）。"""
    # 字典要统计「键的类型」还是「值的类型」？两个都统计更有用
    if isinstance(container, dict):
        keys = Counter(type(k).__name__ for k in container)
        values = Counter(type(v).__name__ for v in container.values())
        return {f"键:{k}": v for k, v in keys.items()} | {f"值:{v}": c for v, c in values.items()}
    return dict(Counter(type(v).__name__ for v in container))


# ============================================================
# 建议规则表：把「什么类型 → 什么建议」数据与逻辑分离
# ============================================================
ADVICE_RULES = [
    (lambda o: isinstance(o, float),
     "float 存在精度误差（0.1+0.2≠0.3），金额场景建议改用 Decimal 或整数分"),
    (lambda o: isinstance(o, list) and not o,
     "空列表无法区分「没有数据」和「数据恰好为空」，建议用 None 占位"),
    (lambda o: isinstance(o, dict) and not o,
     "空字典同上，建议区分「无配置」与「配置为空」两种语义"),
    (lambda o: o is None,
     "None 是合理的空值，但使用前务必先判空（if x is not None）"),
    (lambda o: isinstance(o, str) and not o.strip(),
     "全空白字符串建议 strip() 后再判断，否则 ' ' 会被当成有内容"),
    (lambda o: isinstance(o, (int, float)) and o == 0,
     "零值本身合法，但请确认它不是 None 的替代品（0 和 None 语义不同）"),
    (lambda o: isinstance(o, tuple),
     "元组不可变，适合当「固定配置」；但不能用 append，需要拼接时用 +"),
    (lambda o: isinstance(o, (list, dict)) and not check_mutable(o),
     "该容器行为异常，理论上应该可变"),
]


def suggest(obj: object) -> list[str]:
    """根据数据类型和取值给出针对性建议。"""
    result = [text for condition, text in ADVICE_RULES if condition(obj)]
    return result if result else ["✅ 未发现常见问题，可放心使用"]


# ============================================================
# 主报告函数
# ============================================================
def report(obj: object, label: str = "待检测对象") -> None:
    """打印一份完整的类型体检报告。"""
    print("=" * 68)
    print(f"类型体检报告 · {label}")
    print("=" * 68)

    # 1) 基本信息
    # repr 显示代码层面真实的样子（字符串带引号），比 str 更能暴露问题
    print(f"  值的 repr    : {obj!r}")
    print(f"  值的 str     : {obj}")
    if repr(obj) != str(obj):
        print("                 ↑ 两者不同，说明 repr 更能揭示真实类型")
    print(f"  类型         : {type(obj).__name__}")
    print(f"  真值         : {bool(obj)}" + ("" if obj else "   （Falsy，使用前需判空）"))

    # 2) 可变性（实测得出，不是查表）
    mutable = check_mutable(obj)
    print(f"  可变性       : {'可变' if mutable else '不可变'}   （实测修改是否生效）")

    # 3) 内存占用
    try:
        size = sys.getsizeof(obj)
        print(f"  内存占用     : {size:,} 字节")
        # 说明 getsizeof 只算「对象本身」，不包含它引用的内容
        if isinstance(obj, (list, dict, set, tuple)):
            print(f"                 （注意：这是 {type(obj).__name__} 自身占用，"
                  f"不包含其 {len(obj)} 个元素的内存）")
    except TypeError:
        print("  内存占用     : 无法测量")

    # 4) 容器额外信息
    if isinstance(obj, (list, dict, set, tuple)):
        print(f"  容器长度     : {len(obj)}")
        print(f"  是否为空     : {len(obj) == 0}")
        if len(obj) > 0:
            dist = type_distribution(obj)
            print(f"  类型分布     : {dist}")
    elif isinstance(obj, str):
        print(f"  字符串长度   : {len(obj)}")
        print(f"  strip 后长度 : {len(obj.strip())}  （差值 {len(obj) - len(obj.strip())} 说明有首尾空白）")

    # 5) 建议
    print("\n  【建议】")
    for i, text in enumerate(suggest(obj), start=1):
        print(f"    {i}. {text}")
    print()


# ============================================================
# 测试用例
# ============================================================
def run_tests() -> None:
    """用多种类型的数据验证报告函数。"""
    cases = [
        (42, "普通整数"),
        (0, "零值"),
        (3.14, "浮点数"),
        (0.1 + 0.2, "浮点误差样本"),
        ("hello", "普通字符串"),
        ("   ", "全空白字符串"),
        ("", "空字符串"),
        (True, "布尔 True"),
        (None, "空值 None"),
        ([1, 2, 3], "整数列表"),
        ([], "空列表"),
        ({"a": 1, "b": "x"}, "混合类型字典"),
        ({}, "空字典"),
        ((1, 2), "元组"),
        ({1, 2}, "集合"),
    ]
    for obj, label in cases:
        report(obj, label)
    print(f"✅ 全部 {len(cases)} 个测试用例执行完毕")


def main() -> None:
    """程序入口。"""
    print("🎯 类型体检工具 —— 挑战题参考答案\n")
    run_tests()
    print("💡 进一步扩展方向：")
    print("   1) 支持命令行传参：python type_doctor.py 1 2 3")
    print("   2) 支持递归体检：对嵌套容器逐层生成报告")
    print("   3) 把报告写成 HTML 或 Markdown 文件")
    print("   4) 结合 types 模块的 TypeError 信息，给出更精准的修复建议")


if __name__ == "__main__":
    main()
```
