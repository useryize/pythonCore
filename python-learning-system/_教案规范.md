# Python 系统学习体系 · 教案编写统一规范

> 所有课程文档必须严格遵循本规范，以保证格式一致、可自学、可复习。

## 一、文件命名

- 课程：`L01-环境与第一个程序.md`、`L02-变量与数据类型.md` ……
- 实战：`P01-....md`
- 示例代码：`examples/L02_variable_types.py`

## 二、每课文档结构（必须按此顺序，标题文字可微调）

```markdown
# L02 · 变量与数据类型

| 项目 | 内容 |
| --- | --- |
| 所属阶段 | 阶段一 基础语法 |
| 建议时长 | 90 分钟 |
| 前置知识 | L01 |
| 学习产出 | 能写出…… |

---

## 🎯 一、学习目标
用 3-6 条 `- [ ]` 列出可验证的目标（动词开头：理解 / 能写出 / 能解释）

## 📖 二、知识讲解
按 2.1 / 2.2 / 2.3 … 小节展开。每个知识点必须包含：
- 一句话定义
- 「为什么需要它 / 它解决什么问题」
- 可运行的最小示例（带逐行注释）
- 常见用法与边界情况
- 初学者最容易踩的坑（用 ⚠️ 标注）

## 💻 三、课堂演示代码
一段 30-80 行的完整可运行程序，**每一行都要有中文注释**说明意图。
结尾用 `if __name__ == "__main__":` 入口。

## ⚠️ 四、常见错误清单
表格形式：| 错误现象 | 原因 | 正确写法 |
至少 5 条。

## 🧠 五、知识点速查表
用表格或代码块做一页速查，方便复习。

## 📝 六、本课小结
5-8 条要点 + 一句话总结。

## ✍️ 七、课后作业
- **基础题**（3-5 题，必做）
- **进阶题**（2-3 题）
- **挑战题**（1 题，选做）
每题都要写清「输入 / 输出 / 要求」，标注分值。

## ✅ 八、作业参考答案
每一题都要有参考答案（完整可运行代码 + 关键点讲解）。基础题给完整代码，进阶题给代码，挑战题给思路 + 关键片段 + 完整代码（可折叠用 `<details>`）。

## 🔗 九、延伸阅读与下一课预告
- 推荐练习方向
- 下一课主题
```

## 三、代码规范

- Python 3.10+，UTF-8，中文注释
- 变量命名 `snake_case`，常量 `UPPER_CASE`，类名 `PascalCase`
- 统一用 4 空格缩进
- 演示脚本必须能独立运行，不依赖第三方库
- 涉及文件操作，路径用 `pathlib` 或 `os.path`，且写入到临时目录或当前目录的 `./` 下，不要污染用户目录

## 四、质量红线

1. 不允许出现伪代码占位（如 `# TODO 实现`）
2. 不允许整段代码无注释
3. 概念要讲「为什么」，不能只罗列语法
4. 每课作业必须可独立完成，且参考答案必须真的能跑
5. 严禁出现事实性错误（如 `is` 与 `==` 的区别讲错）
