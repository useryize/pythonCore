### 练习 1：综合参数设计
写一个 `make_profile(name, *, age=18, city="北京", **extra)` 函数：
返回 dict；`extra` 里的键值对要合并进去；并为返回值加上 `"name": name.upper()`。
调用示例：`make_profile("tom", age=20, hobby="篮球", pet="cat")`

<details><summary>参考答案</summary>

```python
def make_profile(name, *, age=18, city="北京", **extra):
    profile = {"name": name.upper(), "age": age, "city": city}
    profile.update(extra)
    return profile

print(make_profile("tom", age=20, hobby="篮球", pet="cat"))
# {'name': 'TOM', 'age': 20, 'city': '北京', 'hobby': '篮球', 'pet': 'cat'}
```
</details>

### 练习 2：闭包计数器
实现一个闭包，每调用一次计数加 1，返回当前计数。

<details><summary>参考答案</summary>

```python
def make_counter(start=0):
    count = start
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

c1 = make_counter()
print(c1(), c1(), c1())   # 1 2 3
c2 = make_counter(10)
print(c2())               # 11，说明两个闭包状态独立
```
</details>

### 练习 3：装饰器实战
实现一个 `@timer` 装饰器，统计被装饰函数的执行耗时并打印。
要求：用 `functools.wraps` 保留原函数元信息。

<details><summary>参考答案</summary>

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 执行耗时 {time.perf_counter() - t0:.4f}s")
        return result
    return wrapper

@timer
def slow_sum(n):
    return sum(range(n))

slow_sum(1000000)
```
</details>

### 练习 4：带参数的装饰器
实现 `@retry(max_times=3, delay=1)`：函数抛异常时自动重试，最多 3 次，每次间隔 1 秒，全失败则抛出最后一个异常。

<details><summary>参考答案</summary>

```python
import time
from functools import wraps

def retry(max_times=3, delay=1):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for i in range(1, max_times + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last = e
                    print(f"第 {i} 次失败: {e}")
                    if i < max_times:
                        time.sleep(delay)
            raise last
        return wrapper
    return decorator
```
</details>

### 练习 5：装饰器顺序
下面代码输出什么？为什么？

```python
def deco_a(func):
    def wrapper(*a, **k):
        print("A 前")
        r = func(*a, **k)
        print("A 后")
        return r
    return wrapper

def deco_b(func):
    def wrapper(*a, **k):
        print("B 前")
        r = func(*a, **k)
        print("B 后")
        return r
    return wrapper

@deco_a
@deco_b
def f():
    print("函数体")
```

<details><summary>参考答案</summary>

```
A 前
B 前
函数体
B 后
A 后
```
自下而上应用（deco_b 先），自上而下执行（A 最外层）。
</details>

### 练习 6：递归经典题
至少完成 3 道，每道都要先写递归再考虑有没有更 Pythonic 的写法：
- 汉诺塔移动次数计算
- 斐波那契数列前 n 项
- 目录/嵌套列表的深度计算（递归版）

<details><summary>参考答案</summary>

```python
def hanoi(n):
    return 1 if n == 0 else 2 * hanoi(n - 1) + 1

def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def depth(obj):
    if isinstance(obj, list):
        return 1 + max((depth(x) for x in obj), default=0)
    return 0

print(depth([1, [2, [3, [4]]]]))  # 4
```
</details>

### 练习 7：自定义生成器
实现一个生成器，产出斐波那契数列的前 n 项，**要求不依赖 itertools 预先算好整个列表**。
再写一个生成器函数版 `fib_gen()`，用 `yield` 实现无限序列，并用 `itertools.islice` 取前 10 项。

<details><summary>参考答案</summary>

```python
from itertools import islice

def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

def fib_gen():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

print(list(fib(10)))
print(list(islice(fib_gen(), 10)))
```
</details>

### 练习 8：上下文管理器
用 `contextlib.contextmanager` 实现一个 `timer(name)` 上下文管理器，with 块退出后打印耗时。

<details><summary>参考答案</summary>

```python
import time
from contextlib import contextmanager

@contextmanager
def timer(name):
    t0 = time.perf_counter()
    print(f"{name} 开始")
    try:
        yield
    finally:
        print(f"{name} 耗时 {time.perf_counter() - t0:.4f}s")

with timer("任务"):
    sum(range(1_000_000))
```
</details>

## Part C · 面向对象（★★★★）

### 练习 9：设计一个类
设计 `BankAccount`（银行账户）类，要求：
- 属性：账户号（只读）、余额
- 方法：存款、取款（余额不足抛异常）、查询、转账
- 用 `__repr__` 提供清晰的输出
- 用 `@property` 保护余额只读
- 余额变更记录流水（列表）

<details><summary>参考答案</summary>

```python
class InsufficientFunds(Exception):
    pass

class BankAccount:
    def __init__(self, acc_no: str, balance: float = 0.0):
        self._acc_no = acc_no
        self._balance = balance
        self.records: list[str] = []

    @property
    def balance(self) -> float:
        return self._balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self._balance += amount
        self.records.append(f"存款 {amount:.2f}")

    def withdraw(self, amount: float) -> None:
        if amount > self._balance:
            raise InsufficientFunds(f"余额不足：{self._balance:.2f} < {amount:.2f}")
        self._balance -= amount
        self.records.append(f"取款 {amount:.2f}")

    def transfer_to(self, target: "BankAccount", amount: float) -> None:
        self.withdraw(amount)
        target.deposit(amount)
        self.records[-1] += f" -> 转给 {target._acc_no}"

    def __repr__(self) -> str:
        return f"BankAccount({self._acc_no}, 余额={self._balance:.2f})"
```
</details>

### 练习 10：dataclass 与继承
用 `@dataclass` 定义 `Shape` 基类（带 area 抽象方法），然后实现 `Circle` 和 `Rectangle`。
要求：自动生成 `__init__`/`__repr__`/`__eq__`，`area()` 各自实现。

<details><summary>参考答案</summary>

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from math import pi

@dataclass
class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...

@dataclass
class Circle(Shape):
    r: float
    def area(self) -> float:
        return pi * self.r ** 2

@dataclass
class Rectangle(Shape):
    w: float
    h: float
    def area(self) -> float:
        return self.w * self.h

print(Circle(1), Rectangle(2, 3))
print(Circle(1) == Circle(1))   # True，靠 dataclass 生成的 __eq__
```
</details>

### 练习 11：魔术方法综合
实现一个 `Vector` 类，支持 `+ - *`、长度 `len()`、相等比较、字符串表示、索引访问。

<details><summary>参考答案</summary>

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, o):
        return Vector(self.x + o.x, self.y + o.y)

    def __sub__(self, o):
        return Vector(self.x - o.x, self.y - o.y)

    def __mul__(self, k):
        return Vector(self.x * k, self.y * k)

    def __len__(self):
        return int((self.x ** 2 + self.y ** 2) ** 0.5)

    def __eq__(self, o):
        return isinstance(o, Vector) and (self.x, self.y) == (o.x, o.y)

    def __getitem__(self, i):
        return (self.x, self.y)[i]

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v = Vector(1, 2) + Vector(2, 3)
print(v, len(v), v[0], v == Vector(3, 5))
```
</details>
