### 练习 1：温度转换器
输入摄氏温度，输出华氏温度。公式：`F = C * 9/5 + 32`。
- 额外要求：做输入合法性校验（非数字输入时给出友好提示）。

<details><summary>参考答案</summary>

```python
def c_to_f(c: float) -> float:
    return c * 9 / 5 + 32

while True:
    raw = input("请输入摄氏温度(输入 q 退出): ").strip()
    if raw.lower() == "q":
        break
    try:
        c = float(raw)
    except ValueError:
        print("输入无效，请输入数字")
        continue
    print(f"{c}℃ = {c_to_f(c):.2f}℉")
```
</details>

### 练习 3：数字游戏（1-100 猜数）
程序随机生成 1-100 的整数，用户猜，程序提示大了/小了/对了，并统计猜了几次。上限 7 次，超过给出提示。

<details><summary>参考答案</summary>

```python
import random

target = random.randint(1, 100)
count = 0
while True:
    guess = int(input("猜一个 1-100 的数: "))
    count += 1
    if guess < target:
        print("小了")
    elif guess > target:
        print("大了")
    else:
        print(f"恭喜，猜对了！共 {count} 次")
        break
    if count >= 7:
        print(f"次数用完了，正确答案是 {target}")
        break
```
</details>

### 练习 5：数列求和
计算 1 + 2 + 3 + ... + 100，分别用 for、while、递归三种方式实现。

<details><summary>参考答案</summary>

```python
def with_for(n):
    return sum(range(1, n + 1))

def with_while(n):
    total, i = 0, 1
    while i <= n:
        total += i
        i += 1
    return total

def with_recursion(n):
    return 0 if n <= 0 else n + with_recursion(n - 1)
```
</details>

输入字符串，判断是否为回文（忽略大小写和空格标点）。

<details><summary>参考答案</summary>

```python
def is_palindrome(s: str) -> bool:
    cleaned = "".join(ch for ch in s.lower() if ch.isalnum())
    return cleaned == cleaned[::-1]
```

### 练习 8：凯撒密码
实现加密和解密：字母表整体位移 3 位。

<details><summary>参考答案</summary>

```python
import string

def caesar(text: str, shift: int = 3, decrypt: bool = False) -> str:
    if decrypt:
        shift = -shift
    out = []
    for ch in text:
        if ch in string.ascii_lowercase:
            out.append(string.ascii_lowercase[(string.ascii_lowercase.index(ch) + shift) % 26])
        elif ch in string.ascii_uppercase:
            out.append(string.ascii_uppercase[(string.ascii_uppercase.index(ch) + shift) % 26])
        else:
            out.append(ch)
    return "".join(out)

print(caesar("Hello, World!"))             # Khoor, Zruog!
print(caesar("Khoor, Zruog!", decrypt=True))  # Hello, World!
```
</details>

### 练习 11：矩阵运算
给定二维列表表示矩阵，实现：矩阵转置、矩阵乘法、行最大值。

<details><summary>参考答案</summary>

```python
def transpose(m):
    return [list(row) for row in zip(*m)]

def mat_mul(a, b):
    bt = transpose(b)
    return [[sum(x * y for x, y in zip(row, col)) for col in bt] for row in a]

m1 = [[1, 2], [3, 4]]
m2 = [[5, 6], [7, 8]]
print(transpose(m1))          # [[1, 3], [2, 4]]
print(mat_mul(m1, m2))        # [[19, 22], [43, 50]]
```
</details>

### 练习 12：break/continue/else 专项
打印 1-20，其中能被 3 整除的用 `continue` 跳过，遇到第一个能被 7 整除的用 `break` 跳出并输出它，
循环正常结束（未被 break）时输出一句提示——用 `for...else` 实现。

<details><summary>参考答案</summary>

```python
for i in range(1, 21):
    if i % 3 == 0:
        continue
    if i % 7 == 0:
        print(f"遇到 {i}，跳出")
        break
    print(i, end=" ")
else:
    print("循环正常结束")
```
