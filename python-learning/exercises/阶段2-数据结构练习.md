### 练习 1：去重且保序
输入 `[1, 2, 2, 3, 1, 4, 3]`，输出去重后的列表，**保持原有顺序**。分别用两种方法实现（集合 + 手动判断）。

<details><summary>参考答案</summary>

```python
nums = [1, 2, 2, 3, 1, 4, 3]

# 方法1：手动判断
seen, out = set(), []
for n in nums:
    if n not in seen:
        seen.add(n)
        out.append(n)
print(out)  # [1, 2, 3, 4]

# 方法2：dict 保序去重（Python 3.7+）
print(list(dict.fromkeys(nums)))  # [1, 2, 3, 4]
```
</details>

### 练习 2：列表陷阱专项
下面代码输出什么？为什么？

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)      # ?

c = [1, 2, 3]
d = c[:]
d.append(4)
print(c)      # ?

e = [1, 2, 3]
f = e.copy()
f[0] = 99
print(e)      # ?

def bad(x, y=[]):
    y.append(x)
    return y
print(bad(1), bad(2))   # ?
```

<details><summary>参考答案</summary>

```
a: [1, 2, 3, 4]   ← b = a 是同一对象引用
c: [1, 2, 3]      ← d = c[:] 创建了新列表
e: [1, 2, 3]      ← .copy() 也是浅拷贝，新对象
bad: [1] [1, 2]   ← 默认参数 y=[] 只求值一次，跨调用共享！
```
</details>

### 练习 3：列表综合
给定 `scores = [88, 92, 59, 75, 100, 43]`，完成：
- 最高分、最低分、平均分
- 排序（升序/降序）
- 找出所有及格（≥60）的分数
- 把不及格的分数替换为 60（用新列表，不改原列表）

<details><summary>参考答案</summary>

```python
scores = [88, 92, 59, 75, 100, 43]
print(max(scores), min(scores), sum(scores) / len(scores))
print(sorted(scores), sorted(scores, reverse=True))
print([s for s in scores if s >= 60])
print([s if s >= 60 else 60 for s in scores])   # 推导式天然是新列表
```
</details>

### 练习 5：字典嵌套
给定订单数据，完成：
- 总金额
- 找出金额最大的订单
- 按客户分组统计

```python
orders = [
    {"id": 1, "customer": "张三", "items": [{"price": 99, "qty": 2}, {"price": 199, "qty": 1}]},
    {"id": 2, "customer": "李四", "items": [{"price": 59, "qty": 3}]},
    {"id": 3, "customer": "张三", "items": [{"price": 299, "qty": 1}]},
]
```

<details><summary>参考答案</summary>

```python
from collections import defaultdict

def total(o):
    return sum(i["price"] * i["qty"] for i in o["items"])

print("总金额:", sum(total(o) for o in orders))
print("最大订单:", max(orders, key=total)["id"])

grouped = defaultdict(int)
for o in orders:
    grouped[o["customer"]] += total(o)
print(dict(grouped))  # {'张三': 496, '李四': 177}
```
</details>

### 练习 6：defaultdict 与缺失键
实现一个「分组计数」：输入若干单词，按首字母分组存成字典。
要求用 `defaultdict`，并演示没有它会报什么错。

<details><summary>参考答案</summary>

```python
from collections import defaultdict

words = ["apple", "banana", "avocado", "blueberry"]

# 没有 defaultdict 时
# d = {}
# d["a"].append("apple")   # KeyError!

d = defaultdict(list)
for w in words:
    d[w[0]].append(w)
print(dict(d))  # {'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry']}
```
</details>

### 练习 8：元组不可变性
下面哪些操作合法？为什么？
```python
t = (1, 2, 3)
t[0] = 99        # ?
a, b, c = t       # ?
print(*t)         # ?
t += (4,)         # ?
```
元组和列表在什么时候可以互相转换？

<details><summary>参考答案</summary>

```
t[0] = 99    → TypeError，元组不可变
a, b, c = t  → 合法，解包赋值
print(*t)    → 合法，1 2 3
t += (4,)   → 合法，创建一个新元组 (1,2,3,4)，原元组不变

转换：list(t) 和 tuple(lst)
```

### 练习 10：deque 与队列
用 `collections.deque` 实现一个「滑动窗口最大值」：
给定数组和窗口大小 k，输出每个窗口的最大值。

```python
nums = [1, 3, -1, -3, 5, 3, 6, 7]
k = 3
```

<details><summary>参考答案</summary>

```python
from collections import deque

def max_slide(nums, k):
    dq = deque()   # 存下标，保持值递减
    out = []
    for i, n in enumerate(nums):
        while dq and dq[0] <= i - k:
            dq.popleft()
        while dq and nums[dq[-1]] <= n:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out

print(max_slide(nums, k))  # [3, 3, 5, 5, 6, 7]
```
</details>
