# 作业 10：并发编程

## 作业说明

这套作业训练的是**「判断该不该并发、并发该怎么选、并发写错了会怎样」**这三层能力。

并发是最容易写出「看起来能跑、偶尔就出错」的代码类型。典型症状：本地测试正常，生产跑一小时后偶发数据错乱；CPU 明明满载却几乎没有提速；线程数加到 200 服务反而挂了。

这套作业的目标不是让你记住 `threading` 的 API，而是让你能回答三个问题：**这个任务的瓶颈在哪？四种并发模型（串行/线程/进程/协程）哪种适合它？选错了会付出什么代价？**

配套代码：`code/10_concurrency/01_threading_basics.py` ~ `08_selection_guide.py`

**建议用时**：6~8 小时

**难度分布**：★★★★☆ 4 题 / ★★★★☆ 4 题 / ★★★★★ 2 题

**题目代码**

```python
import threading

class UnsafeCounter:
    def __init__(self):
        self.count = 0
        self.history = []

    def increment(self):
        self.count += 1

    def add_history(self, item):
        self.history.append(item)


class BankAccount:
    def __init__(self, balance):
        self.balance = balance

    def withdraw(self, amount):
        if self.balance >= amount:
            self.balance -= amount
            return True
        return False

    def deposit(self, amount):
        self.balance += amount


def run_unsafe_counter():
    counter = UnsafeCounter()
    def worker():
        for _ in range(10000):
            counter.increment()
            counter.add_history(_)
    threads = [threading.Thread(target=worker) for _ in range(10)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    return counter


def run_bank_transfer(accounts, rounds=1000):
    def transfer(from_id, to_id, amount):
        for _ in range(rounds):
            src = accounts[from_id]
            dst = accounts[to_id]
            amount_to_move = src.balance // 10
            if src.withdraw(amount_to_move):
                dst.deposit(amount_to_move)
    pairs = [(0, 1), (1, 0), (2, 3), (3, 2)]
    threads = []
    for a, b in pairs:
        t = threading.Thread(target=transfer, args=(a, b, 5))
        threads.append(t)
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    return sum(a.balance for a in accounts)
```

### 第 3 题：线程池的正确使用 ★★★★☆

**题目描述**

实现一个「批量任务执行器」，用 `ThreadPoolExecutor`，要求：

1. 支持提交任务并获取结果
2. 支持**按完成顺序**处理结果（而不是提交顺序）
3. 支持**超时控制**：单个任务超时、整批超时
4. 支持**取消**：尚未开始的任务能被取消
5. 支持**失败隔离**：一个任务失败不影响其他任务，且能收集所有失败原因
6. 支持**进度报告**

```

...  ← 注意顺序是按完成时间，不是提交顺序
```

**题目描述**

下面是一段「多线程下载器」，在测试环境表现良好，生产环境出现：偶发的文件损坏、偶发的死锁、内存持续增长。请审查代码，找出**所有**问题（至少 10 处），按「会导致死锁 / 会导致数据损坏 / 会导致资源泄漏 / 会导致异常丢失 / 设计问题」分类。

```python
import threading
import time
import os

results = []
counter = 0
counter_lock = threading.Lock()
logger_lock = threading.Lock()

def download_one(url, filepath):
    try:
        data = fetch(url)
        with open(filepath, "w") as f:
            f.write(data)
        return filepath
    except Exception:
        pass
    return None

def fetch_batch(urls, max_workers=20):
    threads = []
    for url in urls:
        t = threading.Thread(target=download_one, args=(url, make_path(url)))
        t.daemon = True
        threads.append(t)
        if len(threads) >= max_workers:
            t.start()
            threads.pop(0)
    for t in threads:
        t.start()
        t.join()

def make_path(url):
    return "/data/downloads/" + url.split("/")[-1]

def fetch_batch_retry(urls, retries=3):
    def retry_wrapper(url):
        for i in range(retries):
            result = download_one(url, make_path(url))
            if result:
                return result
            time.sleep(2 ** i)
        raise Exception(f"failed: {url}")

    threads = []
    for url in urls:
        t = threading.Thread(target=retry_wrapper, args=(url,))
        t.start()
        threads.append(t)
    for t in threads:
        t.join()
    return results

def increment_global():
    global counter
    counter += 1

def run_workers(n=100):
    threads = [threading.Thread(target=increment_global) for _ in range(n)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    print(f"结果: {counter}")   # 期望 100，实际会小于 100

def log(message):
    logger_lock.acquire()
    print(f"{time.time()}: {message}")
    logger_lock.release()

def batch_write(records, filepath):
    with open(filepath, "w") as f:
        for record in records:
            try:
                f.write(str(record) + "\n")
                results.append(record)
            except IOError:
                continue

def process_with_pool(urls):
    from concurrent.futures import ThreadPoolExecutor
    with ThreadPoolExecutor(max_workers=10) as executor:
        futures = {executor.submit(download_one, u, make_path(u)): u for u in urls}
        for future in futures:
            print(future.result())

def shutdown_service():
```
