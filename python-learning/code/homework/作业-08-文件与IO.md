**题目描述**

### 第 3 题：代码审查题 —— 文件操作的经典事故现场 ⭐★★★★☆

**题目描述**

下面这段代码是一个「日志归档工具」，已经在生产环境跑了半年。请审查它，找出**所有**问题，并按「会导致数据丢失 / 会导致安全问题 / 会导致跨平台问题 / 只是风格问题」四类归类。

```python
import os
import json
import csv

BASE_DIR = "logs/"

def archive_logs():
    files = os.listdir(BASE_DIR)
    for name in files:
        if name.endswith(".log"):
            old_path = BASE_DIR + name
            new_path = "archive/" + name
            os.rename(old_path, new_path)
            print(f"归档完成: {name}")

def read_config(path):
    with open(path) as f:
        return json.loads(f.read())

def export_users(users, output_file):
    f = open(output_file, "w")
    writer = csv.writer(f)
    writer.writerow(["姓名", "邮箱", "注册时间"])
    for u in users:
        writer.writerow([u.name, u.email, u.register_time])
    f.close()

def load_user_data(filename):
    rows = []
    with open(filename, "r", errors="ignore") as f:
        for line in f:
            parts = line.strip().split(",")
            rows.append({
                "name": parts[0],
                "email": parts[1],
            })
    return rows

def download_report(user_id):
    report_path = "/data/reports/{}/report.csv".format(user_id)
    if os.path.exists(report_path):
        return open(report_path, "r").read()
    else:
        return None

def merge_and_clean(file_a, file_b, output):
    content_a = open(file_a).readlines()
    content_b = open(file_b).readlines()
    merged = []
    for line in content_a + content_b:
        if line.strip():
            merged.append(line)
    with open(output, "w") as f:
        f.writelines(merged)
    os.remove(file_a)
    os.remove(file_b)
```

### 第 6 题：代码审查题 —— 大文件处理的内存陷阱 ★★★★★☆

**题目描述**

下面是一段「大文件」处理代码，生产环境处理 8GB 的日志文件时直接 OOM（内存溢出）导致进程被 kill。请审查并定位所有问题。

```python
import json
import csv
import pickle

def analyze_log(filepath):
    with open(filepath, "r") as f:
        content = f.read()
    lines = content.split("\n")
    total = 0
    errors = {}
    for line in lines:
        if not line:
            continue
        try:
            record = json.loads(line)
            total += record.get("size", 0)
        except json.JSONDecodeError:
            level = line[:20]
            errors[level] = errors.get(level, 0) + 1
    return total, errors

def count_words(filepath):
    with open(filepath, "rb") as f:
        data = f.read()
    text = data.decode("utf-8")
    words = text.split()
    counts = {}
    for w in words:
        counts[w] = counts.get(w, 0) + 1
    return counts

def export_results(results, path):
    with open(path, "wb") as f:
        pickle.dump(results, f)

def merge_files(paths, output):
    all_data = []
    for p in paths:
        with open(p, "rb") as f:
            all_data.append(f.read())
    combined = b"".join(all_data)
    with open(output, "wb") as f:
        f.write(combined)
    print(f"共 {len(combined)} 字节")

def save_records(records, path):
    import pickle
    with open(path, "wb") as f:
        for r in records:
            pickle.dump(r, f)

def read_records(path):
    import pickle
    records = []
    with open(path, "rb") as f:
        while True:
            try:
                records.append(pickle.load(f))
            except EOFError:
                break
    return records

def process_chunks(filepath, chunk_size=8192):
    words = []
    with open(filepath, "rb") as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break
            words.extend(chunk.decode("utf-8").split())
    return words
```


6. **`06_binary_and_large.py`** —— 9 个小节，重点回看 **【6】pickle 反序列化攻击的原理与防御** 和 **【7】【8】大文件流式处理**。第 6、7、9 题的考点全在这里。特别是 **【8】的跨块边界问题**：理解「为什么分块会导致单词被劈开」，你就能理解为什么所有流式文本处理都要处理边界。**这是本模块最容易被面试问到、也最容易在生产中出真实事故的知识点。**
