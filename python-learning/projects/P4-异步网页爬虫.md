## 一、项目需求

构建一个礼貌、高效、可扩展的异步网页爬虫。

### 核心功能

| 功能 | 说明 | 必须 |
|---|---|---|
| 异步抓取 | `asyncio` + `httpx`，并发可控 | ✅ |
| robots.txt | 抓取前必须检查并遵守 robots | ✅ |
| 限速控制 | 每个域名独立的请求间隔 + 全局并发上限 | ✅ |
| 深度爬取 | 从种子 URL 爬取 N 层内同域名链接 | ✅ |
| HTML 解析 | `selectolax` / `BeautifulSoup` / `lxml` | ✅ |
| 内容提取 | 标题、正文、链接、图片 | ✅ |
| 去重 | URL 规范化 + 内容哈希，避免重复抓取 | ✅ |
| 断点续爬 | 状态持久化，中断后继续 | ✅ |
| 多种存储 | JSONL / SQLite / CSV 可切换 | ✅ |
| 重试与降级 | 指数退避 + 失败记录 | ✅ |
| 结构化日志 | 分级日志 + 统计面板 | ✅ |
| 遵守礼仪 | UA 声明、延迟、限并发、robots | ✅ |

### 机器人守则（不可妥协）

1. 必须设置真实可识别的 User-Agent，含联系方式
2. 必须遵守 `robots.txt` 的 `Disallow` 规则
3. 单域名请求间隔 ≥ 1 秒
4. 全局并发 ≤ 10
5. 不抓取需要登录的页面，不绕过反爬机制
6. 只抓取允许抓取的内容，遵守目标站的服务条款

> 本项目仅供学习，请遵守 `robots.txt` 与网站条款，不要用于任何商业或攻击用途。

## 三、必须实现的类（接口参考）

```python
# models.py
@dataclass(frozen=True, slots=True)
class Page:
    url: str
    status_code: int
    title: str
    text: str
    links: tuple[str, ...]
    fetched_at: str

# robots.py
class RobotsManager:
    async def can_fetch(self, url: str, user_agent: str = "*") -> bool: ...
    async def crawl_delay(self, url: str, user_agent: str = "*") -> float: ...

# ratelimit.py
class RateLimiter:
    async def acquire(self, domain: str) -> None: ...   # 按域限速
    async def __aenter__(self): ...
    async def __aexit__(self, *exc): ...

# storage/base.py
class StorageBackend(ABC):
    @abstractmethod
    async def save(self, page: Page) -> None: ...
    @abstractmethod
    async def close(self) -> None: ...

# parser/base.py
class BaseParser(ABC):
    @abstractmethod
    def parse(self, html: str, url: str) -> Page: ...

# state.py
class StateManager:
    def load(self) -> set[str]: ...      # 已完成 URL
    def save(self, urls: set[str]) -> None: ...
```
