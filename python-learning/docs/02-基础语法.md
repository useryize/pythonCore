## 1. 变量与命名

### 1.1 变量 = 名字 → 对象的绑定

Python 里没有 C 那种「先声明类型、再分配内存」。变量只是一个**指向对象的标签**：

```python
# x 不是"装数字 3 的盒子"，而是"指向整数对象 3 的一个名字"
x = 3
print(x)        # 3
print(type(x))  # <class 'int'>

x = "hello"     # 同一个名字，改指向另一个对象，完全合法
print(type(x))  # <class 'str'>
```

这就是**动态类型**：变量的类型由它当前指向的对象决定，随时可以换。

### 1.2 命名规则

```python
# 合法
user_name = "Tom"
__private = 42      # 双下划线开头：约定为"私有"
_data = []          # 单下划线开头：约定为"内部使用"
ClassName = 1       # 合法但违反规范（大写开头留给类）
a1 = 2              # 合法
中文变量 = 3          # 合法（Python 3 支持 Unicode 标识符），但不推荐
```

非法示例（会报 `SyntaxError`）：

```python
1abc = 1        # 不能以数字开头
my-var = 1      # 不能有连字符（会被解析成减法）
my var = 1      # 不能有空格
class = 1       # 不能用关键字
```

关键字列表：`False None True and as assert async await break class continue def del elif else except finally for from global if import in is lambda nonlocal not or pass raise return try while with yield`

**命名规范（PEP 8）**：

| 类型 | 规范 | 示例 |
|---|---|---|
| 普通变量/函数 | `snake_case` | `user_name`, `get_user()` |
| 常量 | 全大写 `UPPER_SNAKE` | `MAX_RETRY = 3` |
| 类 | `PascalCase` | `UserAccount` |
| 内部/私有 | 前置单下划线 | `_cache` |

### 1.3 变量交换

```python
a, b = 1, 2
a, b = b, a     # 交换

a, b, c = 1, 2, 3
a, b, c = c, a, b     # 环状交换，右边先整体求值
```

**解包（unpacking）是 Python 的特色**，后面大量地方会用到：

```python
# 从可迭代对象等量解包
first, second = [10, 20]
print(first, second)      # 10 20

# 星号收集剩余
head, *middle, tail = [1, 2, 3, 4, 5]
print(head, middle, tail) # 1 [2, 3, 4] 5

# 交换变量
x, y = y, x
```

星号解包是真实可用的工具，不只是面试题。

### 2.2 浮点数精度陷阱（高频面试点）

```python
print(0.1 + 0.2)              # 0.30000000000000004  ← 不是 0.3！
print(0.1 + 0.2 == 0.3)       # False

from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3   ← 用字符串构造，不要用 float

print(abs(0.1 + 0.2 - 0.3) < 1e-9)        # True  ← 容差比较
```

原因：二进制无法精确表示 0.1（无限循环小数）。**在处理金额时绝对不要用 float。**

### 2.3 字符串：不可变序列

```python
s = "Hello"
print(type(s), len(s), s[0], s[-1])   # <class 'str'> 5 H o
print(s.upper(), s.replace("l", "L"))  # HELLO HeLLo

# s[0] = "h"  → TypeError: 'str' object does not support item assignment
```

**字符串不可变**：任何"修改"操作都返回**新对象**，原对象不变：

```python
s = "abc"
t = s.upper()
print(s, t)     # abc ABC   ← s 没变
```

### 2.4 常用字符串操作

```python
s = "  Python 3.12  "

print(s.strip())           # 'Python 3.12'   去掉两端空白
print(s.split())           # ['Python', '3.12']
print(s.split("3"))        # ['  Python  ', '.12  ']
print("-".join(["a", "b"]))  # a-b            列表转字符串
print(s.find("Py"))        # 2              找不到返回 -1
print(s.count("t"))        # 2
print(s.isdigit())         # False
print(s.startswith("  P")) # True
print("{} 喜欢 {}".format("我", "Python"))    # 我 喜欢 Python
print(f"{s!r}")            # '  Python 3.12  '  repr 形式
```

### 2.5 三种字符串写法

```python
a = '单引号'
b = "双引号"
c = '''三引号
可以
跨行'''
d = """也可以
跨行并包含 "双引号" """

# 常用：单双引号嵌套免转义
msg = "I'm fine"

# 前缀

```

### 2.6 f-string（现代格式化首选）

```python
name, score = "Tom", 95.678

print(f"{name} 得了 {score} 分")
print(f"{score:.2f}")                  # 95.68     保留两位小数
print(f"{score:>10.2f}")               # 右对齐宽10
print(f"{score:,.2f}")                 # 千分位：95.68 → 1,234.57 类效果
print(f"{name!r}")                     # 'Tom'
print(f"{1234567:_}")                  # 1_234_567  数字分隔符
print(f"{0.1:.5f}")                    # 0.10000

# 对齐表格
print(f"{'名称':<10}{'分数':>8}")
print(f"{'Tom':<10}{95.678:>8.2f}")
```

f-string 是 3.6+ 的特性，2026 年新代码应默认使用。

### 2.7 字符串索引与切片

```python
s = "abcdef"
print(s[1:4])      # 'bcd'   切片 [start:stop]，不含 stop
print(s[:3])       # 'abc'
print(s[3:])       # 'def'
print(s[::2])      # 'ace'   步长 2
print(s[::-1])     # 'fedcba' 反转
print(s[-3:-1])    # 'de'    负索引可以混合
```

**切片规则一句话**：左闭右开 + 支持步长 + 越界不报错。

## 3. 运算符

### 3.1 算术运算符

```python
print(7 / 2)    # 3.5   真除法，永远返回 float
print(7 // 2)   # 3     向下取整除法（地板除）
print(-7 // 2)  # -4    负数向下取整！不是 -3
print(7 % 2)    # 1     取余
print(-7 % 2)   # 1     满足 a == (a // b) * b + (a % b)
print(2 ** 10)  # 1024  幂，右结合：2 ** 3 ** 2 == 2 ** 9 == 512
print(7 / 0)    # ZeroDivisionError
```

两个坑：

- **`-7 // 2 == -4`**：地板除是向负无穷取整，不是截断。银行取整场景要特别小心。
- **`2 ** 3 ** 2 == 512`**：幂运算右结合，等价 `2 ** (3 ** 2)`。

### 3.2 复合赋值与自增

```python
x = 5
x += 1      # 等价 x = x + 1（但对可变对象有区别，见 3.6）
x -= 1
x *= 2
x //= 2
x **= 2

# Python 没有 ++ 和 --！x++ 会报 SyntaxError
x += 1      # 正确写法
```

### 3.3 比较运算符

```python
print(1 < 2 < 3)      # True  链式比较，会展开成 (1<2) and (2<3)
print(3 < 2 < 1)      # False
```

### 3.4 逻辑运算符：短路求值（面试重点）

```python
# and：左边假就短路
print(False and print("不会执行"))   # False
# or：左边真就短路
print(True or print("不会执行"))     # True

# 返回值不一定是布尔值！
print(1 or 2)        # 1     ← 返回第一个真值
print(0 and 2)       # 0     ← 返回第一个假值
print(5 and "a")     # 'a'   ← 都被短路了，返回最后一个
print([] or {})     # {}    空列表假，返回后面的
```

这带来一个实用技巧（**短路实现默认值**）：

```python
# 不用 if 三行
name = name or "匿名"
# 惰性默认值：只在参数没传时求值，避免昂贵的计算
config = expensive_call() if config is None else config
```

短路也是保护机制：

```python
if user is not None and user.is_admin:
    # user 为 None 时不会进入，不会 AttributeError
    ...
```

### 3.5 `==` vs `is`（必考）

| 运算符 | 比较内容 | 触发 |
|---|---|---|
| `==` | 对象的**值**是否相等 | `__eq__` |
| `is` | 两个名字是否指向**同一个对象** | `__is__`（默认即身份） |

```python
a = "hello"
b = "hello"
print(a == b)     # True
print(a is b)     # True（小字符串被驻留/缓存了，恰好成立）

c = "".join(["he", "llo"])
print(c == a)     # True
print(c is a)     # False ← 运行时构造的新对象，值同但身份不同

d = [1, 2]; e = [1, 2]
print(d == e)     # True
print(d is e)     # False

# 字符串驻留（interning）
print("he" is "he")     # True，通常被驻留
print("he" + "llo" is a)  # False，拼接是运行时操作
```

**正确用法**：`is` 只用于和 `None`、`True`、`False` 比较（建议恒等比较），不要用于数字和字符串（虽然小整数和短字符串被缓存，但那是实现细节，不可依赖）。

```python
# 错误：数字不能用 is
if x is 1000: ...     # 可能因为缓存而"正确"，但逻辑不可靠

# 正确
if x == 1000: ...
if x is None: ...     # None 是唯一单例，安全
```

### 3.6 其他运算符

```python
# 成员
print("py" in "python")     # True  子串
print(3 in [1, 2, 3])       # True  元素
print("k" in {"k": 1})      # True  dict 查的是 key！

# 身份
print(None is None)         # True

# 位运算
print(5 & 3, 5 | 3, 5 ^ 3, ~5)     # 1 7 6 -6
print(1 << 4, 256 >> 4)            # 16 16

# 海象运算符 := （3.8+）
n = len([1,2,3])
if (m := n) > 2:
    print("长度为", m)     # 长度为 3
```

`a += b` 与 `a = a + b` 对可变对象不等价：

```python
a = [1, 2]
b = a
a += [3]     # b 也变了（原地修改）
a = a + [3]  # b 不变（创建新对象再重新绑定）
print(b)     # [1, 2, 3] 或 [1, 2]，取决于上面用哪种
```

## 5. 布尔与真值判断

### 5.1 真值规则

Python 中只有以下为**假**：

```python
False, None, 0, 0.0, 0j, "", [], {}, set(), (), range(0)
# 以及所有实现了 __bool__ 返回 False 或 __len__ 返回 0 的自定义对象
```

其余一切皆为真。这解释了很多"诡异"行为：

```python
print(bool(""))        # False 空字符串假
print(bool(" "))       # True  ← 只含空格的字符串是真！常见 bug 来源
print(bool("0"))       # True  ← 字符串 "0" 也是真
print(bool([]))        # False
print(bool([0]))       # True  ← 非空列表就是真，里面是什么无所谓
```

### 5.2 判断写法

```python
# 明确判断：推荐，可读性好
if items:
    ...

# 错误写法：会把空列表当"有东西"
if len(items) > 0: ...     # 能用但不如上面直接
if items != []: ...        # 更差

# 推荐：None 判断
if result is not None: ...    # 不要写 if result != None
if value is None: ...         # 不要写 if not value（0/""/[] 都会进来）

# 三元表达式
label = "有效" if value else "无效"
```

### 5.3 常用真值写法速查

| 想表达 | 写法 |
|---|---|
| 列表非空 | `if items:` |
| 不是 None | `if x is not None:` |
| 字符串有内容 | `if s and s.strip():` |
| 字典有键值对 | `if d:` |
| 数值大于 0 | `if n > 0:`（不要写 `if n:`，因为负数也为真） |

## 6. 分支语句

### 6.1 if / elif / else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print(grade)     # B
```

规则：

- **条件从上往下判断，命中第一个就停**，后面的 elif 不再评估
- 条件最多只有一个会被执行
- `else` 可省略
- 顺序敏感：把 `>= 60` 写在 `>= 90` 前面，90 分也会被判成 C

### 6.2 三元表达式

```python
a, b = 10, 20
max_val = a if a > b else b     # 20
```

### 6.3 match-case（3.10+，结构化匹配）

```python
def handle(cmd):
    match cmd:
        case {"action": "quit"}:
            return "退出"
        case {"action": "move", "dir": d} if d in ("up", "down"):
            return f"向{d}移动"
        case [x, y]:                       # 序列模式
            return f"坐标 {x}, {y}"
        case {"action": action, **rest}:    # **rest 收集剩余键值
            return f"其他动作：{action}，参数 {rest}"
        case str() as s if len(s) > 10:     # 类模式 + 守卫
            return f"长字符串：{s}"
        case _:
            return "无法识别"

print(handle({"action": "quit"}))              # 退出
print(handle([3, 4]))                          # 坐标 3, 4
print(handle({"action": "move", "dir": "up"})) # 向上移动
print(handle({"action": "fly", "speed": 10}))  # 其他动作：fly，参数 {'speed': 10}
```

`match` 不是 `if` 的语法糖，它能做**解构式匹配**：`[x, y]` 只匹配恰好长度为 2 的序列，`case {"a": v}` 只匹配含 `a` 键的字典。代码意图表达能力强得多。

## 7. 循环语句

### 7.1 for 循环

```python
for i in range(5):
    print(i)
# 0 1 2 3 4

# range 的三种形式
print(list(range(5)))            # [0,1,2,3,4]
print(list(range(2, 8)))         # [2,3,4,5,6,7]
print(list(range(2, 20, 3)))     # [2,5,8,11,14,17]

# 遍历可迭代对象
for ch in "Python":
    print(ch, end=" ")           # P y t h o n
print()

for idx, val in enumerate(["a", "b", "c"]):
    print(idx, val)              # 0 a / 1 b / 2 c
```

### 7.2 while 循环

```python
n = 5
while n > 0:
    print(n)
    n -= 1
# 5 4 3 2 1
```

`while True` 配合 `break` 是最常见写法：

```python
while True:
    line = input("> ")
    if line == "quit":
        break
    print("收到:", line)
```

**while vs for 选型**：次数已知用 `for`（不会漏写计数器自增）；次数未知、条件复杂用 `while`。

### 7.3 break 与 continue

```python
for i in range(10):
    if i == 3:
        break          # 直接跳出整个循环
    if i % 2 == 0:
        continue       # 跳过本次，继续下一次
    print(i)
# 输出：1 5 7 9
```

注意 `continue` 在 `while` 里的陷阱——它会跳到条件判断处，因此条件里的自增必须小心：

```python
i = 0
while i < 5:
    i += 1
    if i == 3:
        continue
    print(i)
# 1 2 4 5  ← i 在 continue 之前自增，安全

j = 0
while j < 5:
    if j == 3:
        continue       # 死循环！j 永远不增加
    print(j)
    j += 1
```

### 7.4 循环的 else 子句（必考，但不常用）

**规则**：循环**正常结束**（没有被 `break` 打断）时，`else` 会执行一次。

```python
# 查找质数：循环自然结束说明没找到因数
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            break
    else:
        return True     # 只有没 break 才会走到这里
    return False

print(is_prime(17))     # True
print(is_prime(18))     # False（因数 2 触发 break）

# 更直观写法：找不找得到
def find_target(items, target):
    for i, x in enumerate(items):
        if x == target:
            return i
    else:
        return -1
```

Python 没有 `do...while`，循环 `else` 提供了类似的「循环体至少执行了一次且未中断」的语义。日常推荐用标志变量或上述 `return` 写法，可读性更好。

### 7.5 for...else 与嵌套

```python
# 内层 break 不影响外层 else
for i in range(3):
    for j in range(3):
        if i + j == 3:
            break
    else:
        print(f"内层 i={i} 未 break")
```

## 8. 推导式

### 8.1 列表推导式

```python
# 传统写法
squares = []
for i in range(5):
    squares.append(i ** 2)
print(squares)          # [0, 1, 4, 9, 16]

# 列表推导式
squares = [i ** 2 for i in range(5)]
print(squares)          # [0, 1, 4, 9, 16]

# 带条件过滤
evens = [i for i in range(10) if i % 2 == 0]
print(evens)            # [0, 2, 4, 6, 8]

# 带三元表达式（注意是 if-else，不是 if 过滤）
labels = ["偶" if i % 2 == 0 else "奇" for i in range(5)]
print(labels)           # ['偶', '奇', '偶', '奇', '偶']

# 带函数调用
names = [s.strip().upper() for s in ["  a ", " b", "c  "]]
print(names)            # ['A', 'B', 'C']

# 多层嵌套（等价于双层 for）
pairs = [(i, j) for i in range(2) for j in range(2)]
print(pairs)            # [(0,0), (0,1), (1,0), (1,1)]

# 从已有对象
data = [1, 2, 3, 4]
doubled = [x * 2 for x in data]
print(doubled)          # [2, 4, 6, 8]
```

### 8.2 字典与集合推导式

```python
# 字典推导式：{键表达式: 值表达式 for ...}
sq = {i: i ** 2 for i in range(5)}
print(sq)               # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 反转字典
rev = {v: k for k, v in sq.items()}
print(rev)              # {0: 0, 1: 1, 4: 2, 9: 3, 16: 4}

# 集合推导式：去重
print({x % 3 for x in range(10)})    # {0, 1, 2}
```

### 8.3 生成器表达式

```python
gen = (i ** 2 for i in range(5))     # 注意是小括号
print(type(gen))                     # <class 'generator'>
print(next(gen))                     # 0
print(list(gen))                     # [1, 4, 9, 16]

# 用 sum/max/min 消费生成器：不建列表，省内存
total = sum(i ** 2 for i in range(1000000))
print(total)                         # 333332833333000
```

### 8.4 推导式的代价（面试要点）

推导式只是语法糖，`[f(x) for x in data]` 等价于循环调用 `f`。所以：

```python
# 单个已有列表：用推导式或列表()都只是复制一份（浅拷贝）
a = [1, 2, 3]
b = a.copy()
c = [x for x in a]
print(b is c, b == c)     # False True —— 不同对象

# 但两边改嵌套元素时会互相影响
nested = [[1], [2]]
shallow = [lst[:] for lst in nested]   # 每个子列表都复制 → 深一层
print(shallow)          # [[1], [2]]
```

**什么时候不用推导式**：

- 逻辑复杂、需要 try/except 或多条语句时 → 用普通循环
- 需要 break/continue 时 → 推导式做不到
- 嵌套超过两层时 → 可读性急剧下降，用普通循环

## 10. del 与变量生命周期

### 10.1 三种"删除"

```python
x = [1, 2, 3]

del x              # ① 删除名字绑定，x 从此不可用
# print(x)         # NameError: name 'x' is not defined

y = [1, 2, 3]
y.remove(2)        # ② 删除元素
print(y)           # [1, 3]

z = [1, 2, 3]
z.clear()          # ③ 清空内容
print(z)           # []
```

`del` 作用于**名字**，不是对象本身。如果还有其他名字指向同一对象，对象依然存在：

```python
a = [1, 2, 3]
b = a
del a
print(b)           # [1, 2, 3]  ← 对象还活着，只是名字 a 没了

# 局部变量：函数执行完自动 del
def f():
    tmp = [1, 2, 3]
    return len(tmp)
print(f())         # 3
# print(tmp)      # NameError —— tmp 随函数作用域结束而销毁
```

### 10.2 生命周期：引用计数与垃圾回收

Python 用**引用计数**为主、**循环垃圾回收**为辅管理内存：

```python
a = [1, 2, 3]      # 引用计数 1
b = a              # 引用计数 2
del a              # 引用计数 1
del b              # 引用计数 0 → 对象被回收，内存归还
```

循环引用靠 GC 处理：

```python
import weakref

class Node:
    def __init__(self):
        self.parent = None
        self.children = []

p, c = Node(), Node()
p.children.append(c)
c.parent = p          # 互相引用！引用计数永不归零

print(weakref.ref(p)() is p)     # True，弱引用不阻止回收
# 需要等 gc 触发才真正释放
import gc
gc.collect()
# 之后弱引用返回 None
```

```python
# 错误
if x == None: ...     # 可能触发自定义 __eq__，行为不可控

# 正确
if x is None: ...     # 唯一可靠写法
```

## 12. 综合示例

```python
"""综合演示：文本统计。运行：python demo_basic.py"""

def classify(n: int) -> str:
    """判断正负奇偶。"""
    if n == 0:
        return "零"
    kind = "偶数" if n % 2 == 0 else "奇数"
    return ("正" if n > 0 else "负") + kind


def fizzbuzz(n: int) -> str:
    if n % 15 == 0:
        return "FizzBuzz"
    if n % 3 == 0:
        return "Fizz"
    if n % 5 == 0:
        return "Buzz"

# 统计词频

for w in words:
    freq[w] = freq.get(w, 0) + 1
print("词频:", freq)

long_words = {w for w in words if len(w) > 3}

# ['brown', 'jumps', 'lazy']

# 嵌套循环找因数
for n in (12, 13, 17):

# 循环 else 演示
```

## 本节小结

1. **变量**是名字到对象的绑定；**动态类型**指类型由对象决定，随时可换。命名遵循 PEP 8：`snake_case` 函数变量、`UPPER_SNAKE` 常量、`PascalCase` 类。
2. **解包**是 Python 特色：`a, b = b, a`、`head, *mid, tail = ...`、星号收集剩余。
3. **整数无精度上限**；**浮点有精度问题**（`0.1 + 0.2 != 0.3`），金额计算必须用 `Decimal("0.1")` 而非 `Decimal(0.1)`。
4. **字符串不可变**，一切"修改"返回新对象；切片左闭右开、支持步长、支持负索引。
5. **运算符**：`-7 // 2 == -4`（向负无穷取整）；幂右结合；**没有 `++`**；`and/or` 短路且**返回操作数而非布尔**；**`==` 比值，`is` 比身份**，`is` 只用于 `None/True/False`。
6. **input 永远返回字符串**，需要 `int()`/`float()` 转换；批量读用 `input().split()` + `map`。
7. **真值判断**：只有 `False/None/0/""/空容器` 为假，`" "`（空格）和 `[0]` 都为真。判断非 None 用 `is not None`。
8. **分支**：`if/elif` 自上而下命中即停；`match-case` 支持解构式模式匹配（3.10+）。
9. **循环**：`for` 用 `range/enumerate`，`while` 用于不确定次数；`break` 跳出、`continue` 跳过（`while` 中注意别死循环）；**循环 `else` 仅在未被 break 打断时执行**；`break` 只作用于最内层。
10. **推导式**是循环的语法糖（`[f(x) for x in data] == 循环 append`），等价语句也要建新列表，不是原地修改。小括号变生成器表达式可省内存。
11. **del 删的是名字不是对象**；生命周期由引用计数决定，循环引用靠 GC；判断 `None` 用 `is None`。
12. **写文件优先用 `with`**，并显式 `encoding="utf-8"`。

       ```python
       data = [1,2,3]; ref = data; data += [4]; print(ref)   # [1,2,3,4] 原对象被改
       ```

       ```python
       def all_even(obj):

           return isinstance(obj, int) and not isinstance(obj, bool) and obj % 2 == 0

       ```
