# 03 · 数据结构与容器

> Python 的内置容器是这门语言最被低估的部分。列表、元组、集合、字典四件套加上 `collections`，能覆盖 95% 的业务数据结构需求。这一节把它们讲透，包含那些"能跑但会出 bug"的行为。

## 学习目标

学完本节，你应该能够：

1. 说清 list / tuple / set / dict 各自的定位、可变性与底层实现。
2. 熟练完成四者的创建、增、删、改、查。
3. 正确使用 `index()`、`count()`、`in` 等成员操作，理解它们的时间复杂度。
4. 掌握遍历方式：`for`、下标遍历、`enumerate`、`zip`、字典的 `.items()/.keys()/.values()`。
5. 掌握切片的读写语义与"切片赋值"。
6. 理解嵌套结构，以及 `list.append` 别名、可变默认参数等经典坑。
7. 用 `collections` 中的 `defaultdict`、`Counter`、`deque`、`namedtuple`、`OrderedDict` 替代手写逻辑。
8. 在面试中准确回答"list 和 tuple 区别""何时用 set""如何安全地返回列表"等问题。

## 1. 选型总览

| 类型 | 有序 | 可变 | 重复 | 底层实现 | 典型用途 |
|---|---|---|---|---|---|
| `list` | ✅ | ✅ | ✅ | 动态数组 | 有序序列，可增删 |
| `tuple` | ✅ | ❌ | ✅ | 不可变序列 | 固定记录、dict 键、多返回值 |
| `set` | ✅* | ✅ | ❌ | 哈希表 | 去重、快速成员判断、集合运算 |
| `dict` | ✅* | ✅ | key 唯一 | 哈希表 | 键值映射 |

`*` Python 3.7+ 起 dict 和 set 都保证插入顺序，所以"有序"对四者全为真；差别在 3.7 之前不成立，现在不再是选型理由。**真正的差别是可变性与性能特征。**

选择直觉：

- **顺序有意义、要增删** → `list`
- **顺序有意义、不改（想防止被改）** → `tuple`
- **只要去重/快速判断存在性** → `set`
- **需要"名字 → 值"的映射** → `dict`

## 2. 列表 list

### 2.1 创建

```python
empty = []                       # 空列表
nums = [1, 2, 3]
mixed = [1, "a", True, None, [2, 3]]   # 元素类型可以不同

a = [1, 2, 3]
b = [1, 2, 3]
c = [1, 2, 3]
print(a is b)        # False —— 字面量每次新建
print(a == b)        # True  —— 值相等

# ⚠ 陷阱：乘号是"重复引用"，不是"深拷贝"
d = [[]] * 3
d[0].append(1)
print(d)             # [[1], [1], [1]]  ← 三个元素是同一个列表！

# 正确写法
e = [[] for _ in range(3)]
e[0].append(1)
print(e)             # [[1], [], []]

# from 字符串得到字符列表
print(list("abc"))   # ['a', 'b', 'c']
print(list(range(3)))# [0, 1, 2]
```

`[[]] * 3` 是面试必问——它重复的是引用，不是对象。

### 2.2 增

```python
items = [1, 2]

items.append(3)         # 尾部追加单个元素 → [1, 2, 3]
items.append([4, 5])    # 追加整个列表作为【一个】元素 → [1, 2, 3, [4, 5]]
items.extend([6, 7])    # 逐个追加 → [1,2,3,[4,5],6,7]
items.insert(0, 0)      # 在下标 0 处插入 → [0,1,2,3,[4,5],6,7]

print(len(items))       # 7
```

区别速记：`append` 加一个（可以是任何东西），`extend` 展开加多个。

### 2.3 删

```python
items = [1, 2, 3, 2, 4]

items.remove(2)        # 删除第一个值等于 2 的元素 → [1,3,2,4]
items.pop()            # 删除并返回最后一个 → [1,3,2]
print(items.pop(0))    # 删除并返回下标 0 的元素 → 1，列表变为 [3,2]
items.pop(99)          # IndexError: pop index out of range

items = [1, 2, 3, 2]
del items[0]           # 按下标删除 → [2,3,2]

items = [1, 2, 3, 2]
items.remove(99)       # ValueError: list.remove(x): x not in list

items = [1, 2, 3, 2]
items[1:3] = []        # 按切片删除 → [1,2]

items = [1, 2, 3]
items.clear()          # → []
```

四种删除方式互不通用：`remove` 按值、`pop` 按下标、`del` 按下标/切片、`clear` 全清。

### 2.4 改

```python
items = [1, 2, 3]
items[0] = 100                  # 按下标赋值 → [100,2,3]
items[1:3] = [20, 30, 40]        # 切片赋值，长度可变 → [100,20,30,40]
items[::2] = [0, 0]              # 按步长 → [0,20,0,40]
items[1] = (7, 8)                # 元组也能赋值给单个位置 → [0,(7,8),0,40]
# items[1:2] = [1, 2, 3]         # 可以，list 会自动扩容
# items[1:2] = 5                 # TypeError：只能赋可迭代对象
```

**切片赋值可以改变列表长度**，这是它的独特能力。

### 2.5 查

```python
items = [10, 20, 30, 20, 40]

print(items[0])       # 10    按下标
print(items[-1])      # 40    负索引
print(items.index(20))# 1     第一次出现的位置，找不到抛 ValueError
print(items.count(20))# 2     出现次数
print(20 in items)    # True  成员判断
print(items[1:3])     # [20, 30]  切片返回新列表

# 找不到时的优雅处理
if 99 in items:
    idx = items.index(99)
else:
    idx = -1

# get 的等价写法（list 没有 get，用条件表达式）
idx = items.index(99) if 99 in items else -1
```

### 2.6 常用方法总览

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

nums.sort()                      # 原地升序，返回 None
nums.sort(reverse=True)          # 降序
nums.sort(key=lambda x: -x)      # 按规则排序：降序
print(nums)                      # [9,6,5,4,3,2,1,1]

nums.reverse()                   # 原地反转，返回 None
nums.insert(0, 99)               # 插入
nums.remove(99)                  # 按值删第一个

nums = [3, 1, 4]
print(nums.index(1))             # 1
print(nums.count(1))             # 1

nums = [1, 2]
extra = [3, 4]
print(nums + extra)              # [1,2,3,4]     新列表
print(nums * 2)                  # [1,2,1,2]     重复引用
print(nums.extend(extra))        # None！返回 None，不能链式调用
```

**易错**：所有原地修改方法（`sort`、`reverse`、`extend`、`append`、`insert`、`remove`）都返回 `None`，因此不能写 `x = x.sort()`。

### 2.7 排序：sort 与 sorted

```python
nums = [3, 1, 2]

nums.sort()                 # 原地排序，返回 None → nums 变了
print(nums)                 # [1, 2, 3]

result = sorted([3, 1, 2])  # 返回新列表，原列表不变
print(result, nums)         # [1,2,3] [1,2,3]

# 多级排序
users = [("bob", 25), ("alice", 30), ("carol", 25)]
print(sorted(users, key=lambda u: (u[1], u[0])))
# [('alice', 30), ('bob', 25), ('carol', 25)]  按年龄升序，同年龄按名字
```

### 2.8 常用技巧

```python
# 去重且保持顺序
items = [3, 1, 3, 2, 1]
uniq = list(dict.fromkeys(items))     # [3, 1, 2]  利用 dict 保序
# 或
uniq = list(dict.fromkeys(items))

# 或者（3.7+ 官方推荐）
uniq = list(dict.fromkeys(items))

# 排序去重
print(sorted(set(items)))             # [1, 2, 3]

# 展平一层
nested = [[1, 2], [3], [4, 5]]
flat = [x for sub in nested for x in sub]
print(flat)                           # [1,2,3,4,5]

# 分组
from itertools import groupby
words = ["apple", "avocado", "banana", "blueberry"]
for k, g in groupby(sorted(words), key=lambda w: w[0]):
    print(k, list(g))
# a ['apple', 'avocado'] / b ['banana', 'blueberry']
```

## 3. 元组 tuple

### 3.1 创建与不可变性

```python
t = (1, 2, 3)
print(type(t), len(t), t[0])

single = (5,)          # ⚠ 单元素元组必须有逗号！
print(type(single))    # <class 'tuple'>

no_paren = 5           # 这是 int，不是 tuple
print(type(no_paren))  # <class 'int'>

# tuple() 转换
print(tuple([1, 2]))   # (1, 2)
print(tuple("ab"))     # ('a', 'b')
print(tuple({1: 2}))   # (1,)  取键
```

单元素元组漏逗号是新手高频错误，`(5)` 和 `5` 完全等价。

### 3.2 为什么用元组

```python
# 1. 作为 dict 的键（不可变才能哈希）
d = {(1, 2): "点", (3, 4): "另一个点"}
print(d[(1, 2)])               # 点

# 2. 可哈希，能放进 set
locations = {(0, 0), (1, 1), (0, 0)}
print(len(locations))          # 2  自动去重

# 3. 防止意外修改
CONST = (10, 20)               # 约定用元组存常量

# 4. 多返回值
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4])
print(lo, hi)                  # 1 4
```

### 3.3 元组的"伪不可变"

```python
t = ([1, 2], 3)       # 里面装了列表
t[0].append(99)       # 合法！元组自身没变
print(t)              # ([1, 99], 3)

t[0] = [9]            # TypeError：'tuple' object does not support item assignment
```

**不可变是浅层的**：元组里的可变元素照样能被修改。

### 3.4 常用操作

```python
t = (3, 1, 2)
print(sorted(t))               # [1, 2, 3]  注意返回的是 list！
print(list(t))                 # [3, 1, 2]
print(max(t), min(t), t.count(1), t.index(1))   # 3 1 1 1
print(3 in t)                  # True

# 连接与重复
print((1, 2) + (3,))           # (1, 2, 3)
print((0,) * 3)                # (0, 0, 0)

# 命名元组形式
a, b, c = t                    # 解包
print(a, b, c)                 # 3 1 2
print(t[0], t[-1])             # 3 2
```

### 3.5 list vs tuple 深度对比（面试题）

| 维度 | list | tuple |
|---|---|---|
| 可变性 | 可变 | 不可变 |
| 内存 | 额外分配，列表整体迁移 | 更紧凑 |
| 哈希 | 不可哈希（`TypeError: unhashable type: 'list'`） | 元素都可哈希时可哈希 |
| 访问速度 | 略慢（多一层间接） | 略快 |
| 语义 | "这一组会变的项" | "这一组固定的记录" |

```python
try:
    {1: "a"}[]
except TypeError as e:
    print(e)      # unhashable type: 'list'

# tuple 是否可哈希取决于元素
print(hash((1, 2)))       # 可以
try:
    hash(([1], 2))
except TypeError as e:
    print(e)              # unhashable type: 'list'
```

## 4. 集合 set

### 4.1 创建与去重

```python
s1 = {1, 2, 3}
s2 = {1, 2, 3, 3, 2}         # 重复自动去掉
print(s2)                    # {1, 2, 3}

empty = set()                # ⚠ 不能用 {} —— 那是空字典
print(type(empty))           # <class 'set'>

print({x % 3 for x in range(10)})    # {0, 1, 2} 集合推导式
print(set([1, 1, 2]), set("aab"))    # {1, 2} {'a', 'b'}

# 不可哈希元素不能进集合
try:
    {1, [2]}
except TypeError as e:
    print(e)                 # unhashable type: 'list'
```

### 4.2 增删改查

```python
s = {1, 2}

s.add(3)             # 添加单个
s.update([4, 5])     # 添加多个
s.discard(99)        # 不存在也不报错 ← 推荐
s.remove(99)         # 不存在抛 KeyError
s.pop()              # 随机弹出一个

s = {1, 2, 3}
del s[1]             # 按值删除（set 不支持按下标）→ 合法但少见
```

**用 `discard` 不用 `remove`** 是社区惯例：批量清理时 `discard` 更安全。

### 4.3 集合运算（核心价值）

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)    # {1,2,3,4,5,6}       并集 union
print(a & b)    # {3, 4}               交集 intersection
print(a - b)    # {1, 2}               差集 difference（a 独有）
print(a ^ b)    # {1,2,5,6}            对称差（只在一边出现）
print(a | b == a.union(b))             # 方法等价

# 对应方法
a.union(b); a.intersection(b); a.difference(b); a.symmetric_difference(b)
a.intersection_update(b)   # 原地求交

# 关系判断
print(a <= {1,2,3,4,5})    # True 子集
print({1} < a)             # True 真子集
print(a.isdisjoint({9, 10}))# True 无交集
```

### 4.4 集合的真正用途：快速成员判断

```python
# 反面教材：list 的 in 是 O(n)
allow_list = ["apple", "banana"]
print("apple" in allow_list)      # O(2)，数据量大就慢

# 正面：set 的 in 是 O(1)
allow_set = {"apple", "banana"}
print("apple" in allow_set)       # O(1)

# 从列表建 set 只做一次
raw = ["a", "b", "a"] * 10000
allow = set(raw)                  # 建一次 O(n)
print("a" in allow)               # 之后都是 O(1)
```

**性能对比（面试可能追问）**：100 万次判断时，set 比 list 快几个数量级，因为 set 用哈希表，list 要逐个比较。

### 4.5 frozenset

```python
s = frozenset({1, 2, 3})          # 不可变集合，可哈希
print(s | {4})                    # 支持运算
d = {s: "value"}                  # 能作为 dict 的键
try:
    {1, 2}.add(3)
except AttributeError as e:
    print(e)                      # 'frozenset' object has no attribute 'add'
```

## 5. 字典 dict

### 5.1 创建

```python
d1 = {}                              # 空字典
d2 = {"name": "Tom", "age": 25}
d3 = dict(name="Tom", age=25)
d4 = dict([("a", 1), ("b", 2)])      # 从键值对序列
d5 = {"x": 1, **{"y": 2}}            # 解包合并
print(d1, d2, d3, d4, d5)

# key 必须是不可哈希对象
try:
    {"[1]": 1}
except TypeError as e:
    print(e)                         # unhashable type: 'list'

# key 可以是任意可哈希对象，包括元组
print({(1, 2): "point", 3.14: "pi", None: "none", True: "bool"})
# 注意 True 和 1 是同一个 key（哈希与相等都相同）
print({True: 1, 1: 2})               # {True: 2}
```

### 5.2 增改

```python
d = {"a": 1}

d["b"] = 2                  # 新增/覆盖
d.update({"c": 3, "a": 10}) # 批量更新
d.update([("d", 4)])        # 从序列更新
d.setdefault("e", 5)        # 存在则返回原值，不存在则设默认值并返回该值
print(d)                    # {'a': 10, 'b': 2, 'c': 3, 'e': 5, 'd': 4}
```

`setdefault` 的返回值语义容易混：

```python
d = {"k": 1}
print(d.setdefault("k", 99))    # 1   存在，返回原值，不改
print(d.setdefault("n", 99))    # 99  不存在，设入 99 并返回它
print(d)                        # {'k': 1, 'n': 99}
```

### 5.3 删

```python
d = {"a": 1, "b": 2, "c": 3}

del d["a"]               # 按键删除，不存在抛 KeyError
print(d.pop("b"))         # 2   弹出并返回值，不存在抛 KeyError
print(d.pop("zz", None))  # None  不存在返回默认值 ← 推荐
d.clear()                 # 清空
```

### 5.4 查：`get` 与 `[]` 的区别（高频）

```python
d = {"a": 1}

print(d["a"])             # 1
print(d.get("a"))         # 1
print(d.get("z"))         # None   ← 不报错
print(d.get("z", 0))      # 0      指定默认值
print(d["z"])             # KeyError: 'z'  ← 会崩
```

**规则**：`[]` 用于"key 一定存在"；`get` 用于"key 可能不存在"。写业务代码时误用 `[]` 是运行时崩溃的常见来源。

### 5.5 遍历

```python
d = {"a": 1, "b": 2, "c": 3}

for k in d:              # 遍历 key（默认）
    print(k)

for k, v in d.items():   # 遍历 key + value  ← 最常用
    print(k, v)

for k in d.keys():
    print(k)

for v in d.values():
    print(v)

# 反转（Python 3.8+）
for k in reversed(d):
    print(k)             # c b a

# 按值排序遍历
for k, v in sorted(d.items(), key=lambda kv: kv[1], reverse=True):
    print(k, v)          # c 3 / b 2 / a 1
```

遍历 dict 时**不能修改它的结构**（增删 key）：

```python
d = {"a": 1, "b": 2}
for k in d:
    del d[k]             # RuntimeError: dictionary changed size during iteration
# 正确：遍历副本
for k in list(d.keys()):
    del d[k]
print(d)                 # {}
```

### 5.6 常用方法

```python
d = {"a": 1, "b": 2, "c": 3}

print(d.keys())       # dict_keys(['a','b','c'])  视图，支持集合运算
print(d.values())     # dict_values([...])
print(d.items())      # dict_items([...])

print(d.get("a"))             # 1
print(d.get("z", "default"))  # default
d.setdefault("d", 4)           # 见上
d.update({"e": 5})
print(d.pop("e"))              # 5
print(len(d), "a" in d)        # 4 True

# keys 视图支持集合运算（很实用）
defaults = {"timeout": 3, "retry": 2}
config = {"timeout": 10}
merged = {**defaults, **config}      # config 覆盖 defaults → {'timeout': 10, 'retry': 2}
print(defaults.keys() & config.keys())   # {'timeout'}  共同关注项
```

### 5.7 嵌套与深浅拷贝

```python
original = {"list": [1, 2], "dict": {"k": "v"}}

# 浅拷贝：外层新，内层共享
shallow = original.copy()
shallow["list"].append(3)
print(original["list"])        # [1, 2, 3]  ← 被影响了

# 深拷贝
import copy
deep = copy.deepcopy(original)
deep["list"].append(4)
deep["dict"]["k"] = "changed"
print(original["list"])        # [1, 2, 3]
print(original["dict"])        # {'k': 'v'}
print(deep["list"], deep["dict"])  # [1,2,3,4] {'k': 'changed'}

# 用 copy.deepcopy 传参/返回，避免外部改内部数据
```

## 6. 切片

### 6.1 通用规则

```python
seq[start:stop:step]     # 左闭右开；start/step 可省

s = [0, 1, 2, 3, 4, 5]
print(s[1:4])      # [1, 2, 3]
print(s[:2])       # [0, 1]
print(s[4:])       # [4, 5]
print(s[::2])      # [0, 2, 4]
print(s[::-1])     # [5,4,3,2,1,0]
print(s[-2:])      # [4, 5]
print(s[10:20])    # []  越界返回空，不报错

# 越界会静默截断——危险来源
i = 10
print(s[:i])       # [0..5] 全取，程序不会报错但逻辑错了
```

### 6.2 切片类型

```python
print([1,2,3][0:2])        # list
print((1,2,3)[0:2])        # tuple
print("abcdef"[1:3])       # str
print(bytes(b"abcdef")[1:3])  # bytes
# set 不支持切片（无序）
```

### 6.3 切片赋值：改变长度

```python
items = [1, 2, 3, 4, 5]

items[1:3] = [99]              # [1, 99, 4, 5]      长度 5→4
items[1:3] = [7, 8, 9, 10]     # [1, 7, 8, 9, 10, 4, 5]  长度 5→7
items[::2] = []                # [8, 10, 5]          按步长删
items[:] = [0]                 # [0]                整体替换
# items[0] = 1                # TypeError：标量不能赋给切片
```

### 6.4 切片返回新对象

```python
a = [1, 2, 3]
b = a[:]        # 等价 a.copy()
b.append(4)
print(a)         # [1,2,3]  原对象不变
```

## 7. 遍历方式全景

```python
nums = [10, 20, 30]
names = ["a", "b", "c"]

# 1. 直接遍历值（不需要下标时首选）
for n in nums: ...

# 2. enumerate：同时拿下标和值
for i, n in enumerate(nums): ...          # 0 10 / 1 20 / 2 30
for i, n in enumerate(nums, start=1): ...  # 1 10 / ...

# 3. 下标遍历（需要修改元素时）

    nums[i] *= 2

# 4. zip：多个序列并行遍历
for n, s in zip(nums, names):

print(list(zip([1,2,3], ["a"])))         # [(1, 'a')]
print(list(zip([1,2,3], ["a"], strict=True)))  # ValueError（3.10+）

# 5. 遍历字典
d = {"x": 1}
for k in d: ...          # key
for v in d.values(): ... # value
for k, v in d.items(): ...  # 两者

# 6. 生成器遍历（省内存）

for n in reversed(nums): ...
```

## 8. 常见坑

### 8.1 坑一：`list.append` 别名

```python
def add_item(item, target_list=[]):     # ⚠ 可变默认参数
    target_list.append(item)
    return target_list

print(add_item(1))    # [1]
print(add_item(2))    # [1, 2]  ← 上次的结果还在！
print(add_item(3))    # [1, 2, 3]

# 默认值在【函数定义时】只求值一次，被所有调用共享
```

正确写法一（推荐）：

```python
def add_item(item, target_list=None):
    if target_list is None:
        target_list = []
    target_list.append(item)
    return target_list

print(add_item(1))    # [1]
print(add_item(2))    # [2]  互不影响
```

正确写法二（Python 3.x 也可用，但不如上面清晰）：

```python
def add_item(item, target_list=()):
    target_list = list(target_list)   # 必须先复制
    target_list.append(item)
    return target_list
```

**记忆点**：默认参数用 `None` 占位，函数体内判断。这是面试必问的"经典 bug"。

## 9. collections 工具箱

### 9.1 defaultdict

```python
from collections import defaultdict

# 普通 dict 统计时必须先判断
counts = {}
for ch in "hello":
    if ch not in counts:
        counts[ch] = 0
    counts[ch] += 1
print(counts)      # {'h':1,'e':1,'l':2,'o':1}

# defaultdict 自动初始化
counts = defaultdict(int)
for ch in "hello":
    counts[ch] += 1        # 不存在的 key 自动变 0
print(dict(counts))        # {'h':1,'e':1,'l':2,'o':1}

# 分组
words = ["apple", "avocado", "banana"]
groups = defaultdict(list)
for w in words:
    groups[w[0]].append(w)
print(dict(groups))
# {'a': ['apple', 'avocado'], 'b': ['banana']}

# 嵌套分组（很实用）
nested = defaultdict(lambda: defaultdict(list))
nested["a"]["x"].append(1)
print(dict(nested))     # {'a': {'x': [1]}}

# 其他 factory
d_list = defaultdict(list);      d_list["k"].append(1)
d_set = defaultdict(set);        d_set["k"].add(2)
d_str = defaultdict(str);        d_str["k"] += "ab"
d_int = defaultdict(int);        print(d_int["missing"])   # 0
d_none = defaultdict(lambda: None)
print(dict(d_str), dict(d_int))
# {'k': 'ab'} {'missing': 0}
```

注意：`defaultdict` 的 factory 不接受参数，所以 `defaultdict(dict)` 可以（`dict()` 无参），但 `defaultdict(list)` 不能写成带参形式。

### 9.2 Counter

```python
from collections import Counter

# 最常用：计数
c = Counter("hello")
print(c)                        # Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})
print(c.most_common(2))         # [('l', 2), ('h', 1)]  最高频两项
print(c["l"], c["z"])           # 2 0  ← 不存在的键返回 0，不报错！
print(c["z"])                   # 0（不是 KeyError）

# 直接接受可迭代对象 / 映射
print(Counter([1, 2, 2, 3, 3, 3]))   # Counter({3:3, 2:2, 1:1})
print(Counter({"a": 3, "b": 1}))      # Counter({'a': 3, 'b': 1})

# 找出出现次数最多的元素
items = ["a", "b", "b", "c", "c", "c"]
print(Counter(items).most_common(1)[0][0])    # c

# 集合运算
c1 = Counter("aab")
c2 = Counter("bc")
print(c1 + c2)      # Counter 加法：计数相加
print(c1 - c2)      # 只保留正差值
print(c1 & c2)      # 取交集（计数取 min）
print(c1 | c2)      # 取并集（计数取 max）

# 用 Counter 实现"找众数"和"找前 K 常见元素"
print(Counter([5,1,5,3,5,3,3]).most_common())
# [(5, 3), (3, 3), (1, 1)]  计数多者在前，同计数按首次出现顺序
```

**替代场景**：`Counter` + `most_common` 是"Top N 统计"的教科书答案，比手写排序快且清晰。

### 9.3 deque

```python
from collections import deque

# 双端队列：两端都能高效增删
d = deque([1, 2, 3])
d.append(4)        # 右端加
d.appendleft(0)    # 左端加
d.pop()            # 右端删
d.popleft()        # 左端删
print(list(d))     # [1, 2, 3]

# 限定长度，超出自动丢最旧的（队列场景）
q = deque(maxlen=3)
for i in range(5):
    q.append(i)
print(list(q))     # [2, 3, 4]  只保留最近 3 个

# 滑动窗口最大值
from collections import deque

def max_slide(nums, k):
    window = deque()       # 存下标，保持对应值递减
    result = []
    for i, x in enumerate(nums):
        while window and window[0] <= i - k:      # 移除窗口外的
            window.popleft()
        while window and nums[window[-1]] <= x:    # 移除比当前小的
            window.pop()
        window.append(i)
        if i >= k - 1:
            result.append(nums[window[0]])
    return result

print(max_slide([1,3,-1,-3,5,3,6,7], 3))   # [3,3,5,5,6,7]
```

**为什么用 deque 而不是 list**：list 的 `pop(0)` 是 O(n)（要搬移所有元素），`deque.popleft()` 是 O(1)。做队列、BFS、滑动窗口时性能差一个数量级。

### 9.4 namedtuple

```python
from collections import namedtuple

# 具名元组：既有元组的性能，又有字段名
Point = namedtuple("Point", ["x", "y"])
p = Point(1, 2)
print(p)                  # Point(x=1, y=2)
print(p.x, p.y)           # 1 2  ← 比 p[0] 可读
print(p[0])               # 1     仍然支持索引（是 tuple 子类）
x, y = p                  # 支持解包
print(x + p.x)            # 2

# 默认值
Color = namedtuple("Color", ["r", "g", "b"], defaults=(0, 0, 0))
print(Color(255))         # Color(r=255, g=0, b=0)

# _replace：非破坏性修改（返回新对象）
p2 = p._replace(y=99)
print(p)                  # Point(x=1, y=2)  ← 原对象不变
print(p2)                 # Point(x=1, y=99)

# _asdict
print(p._asdict())        # {'x': 1, 'y': 2}

# 轻量级类（通常更适合，因为它可以有方法、有类型注解）
class Point2:
    def __init__(self, x: int, y: int):
        self.x, self.y = x, y

    def dist(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

print(Point2(3, 4).dist())   # 5.0
```

**选型**：`namedtuple` 适合纯数据记录（内存小、比较快）；一旦需要方法、属性校验、默认值可变，就用普通类。Python 3.6.1+ 还支持 `typing.NamedTuple`，能加类型注解和方法，是更好的选择。

### 9.5 OrderedDict 与其他

```python
from collections import OrderedDict

# Python 3.7+ 普通 dict 已保证插入顺序，普通 dict 足够

od.move_to_end("a")        # 移到末尾（普通 dict 做不到）
```

## 10. 综合示例

```python
"""综合演示：容器综合使用。运行：python demo_containers.py"""

from collections import Counter, defaultdict, deque


def word_stats(text: str) -> dict:
    """统计词频与长度分布（defaultdict + Counter 组合）。"""
    words = text.lower().split()
    freq = Counter(words)

    # 最常见的 3 个词
    top3 = freq.most_common(3)

    # 按首字母分组
    groups = defaultdict(list)
    for w in words:
        groups[w[0]].append(w)

    # 长度分布
    by_len = defaultdict(list)
    for w in words:
        by_len[len(w)].append(w)

    return {
        "总数": len(words),
        "唯一词数": len(freq),
        "最高频": top3,
        "首字母分组": {k: v for k, v in sorted(groups.items())},
        "按长度": dict(sorted(by_len.items())),
    }


def dedupe_keep_order(items: list) -> list:
    """去重并保持原顺序。"""
    return list(dict.fromkeys(items))


def two_sum(nums: list, target: int) -> list | None:
    """用 dict 在 O(n) 内找两数之和。"""
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
    return None


def flatten(items: list) -> list:
    """递归展平任意深度嵌套。"""
    out = []
    for it in items:
        if isinstance(it, list):
            out.extend(flatten(it))
        else:
            out.append(it)
    return out


def merge_dicts(base: dict, override: dict) -> dict:
    """合并字典，override 优先，且不修改原字典。"""
    return {**base, **override}


if __name__ == "__main__":
    text = "the quick brown fox jumps over the lazy dog the fox"

    stats = word_stats(text)
    print("词数:", stats["总数"])
    print("唯一词:", stats["唯一词数"])
    print("最高频:", stats["最高频"])
    # 最高频: [('the', 3), ('fox', 2), ('brown', 1)]
    print("首字母分组:", stats["首字母分组"])

    print("\n去重:", dedupe_keep_order([3, 1, 3, 2, 1]))
    # 去重: [3, 1, 2]

    print("两数之和:", two_sum([2, 7, 11, 15], 9))
    # 两数之和: [0, 1]

    print("展平:", flatten([1, [2, [3, [4]], 5]]))
    # 展平: [1, 2, 3, 4, 5]

    print("合并:", merge_dicts({"host": "localhost", "port": 80},
                             {"port": 8080}))
    # 合并: {'host': 'localhost', 'port': 8080}

    # 深浅拷贝对比
    orig = {"nums": [1, 2]}
    shallow = orig.copy()
    deep = {k: (v[:] if isinstance(v, list) else v) for k, v in orig.items()}
    shallow["nums"].append(3)
    deep["nums"].append(4)
    print("原字典:", orig, "| 浅拷贝:", shallow, "| 深拷贝:", deep)
    # 原字典: {'nums': [1, 2, 3]}  ← 被浅拷贝影响
```

## 11. 面试常考速答

1. **list 和 tuple 区别**：可变性、是否可哈希、内存与访问性能、底层实现、语义。
2. **`[] * 3` 得到什么**：`[[], [], []]`，但三个元素是同一个列表对象；应写 `[[] for _ in range(3)]`。
3. **可变默认参数为何是 bug**：默认值在定义时求值一次，被所有调用共享；改用 `None` 占位。
4. **函数返回 list 的风险**：调用方可修改内部状态；返回新对象或副本。
5. **set vs list**：去重、成员判断 O(1) vs O(n)、集合运算支持、必须可哈希、无索引无序。
6. **dict 查找 vs list 查找**：平均 O(1) vs O(n)；数据量大时 set/dict 优势明显。
7. **`dict.fromkeys` 的陷阱**：`dict.fromkeys(keys, [])` 所有 value 共享同一个列表，必须用 `dict.fromkeys(keys, [] )` 配合后续赋值或用 `dict(zip(keys, [[]]*len(keys)))`，实际推荐 `{k: [] for k in keys}`。

```python
# ⚠ 陷阱
d = dict.fromkeys(["a", "b"], [])
d["a"].append(1)
print(d)          # {'a': [1], 'b': [1]}  两个 key 共享同一个 list

# 正确
d = {k: [] for k in ["a", "b"]}
d["a"].append(1)
print(d)          # {'a': [1], 'b': []}
```

## 本节小结

1. **选型**：会变的用 `list`，不变的用 `tuple`，去重/集合运算用 `set`，键值映射用 `dict`。Python 3.7+ 四者都保序，真正的差别是**可变性与性能**。
2. **list 增删改查**：`append`（加一个）/ `extend`（加多个）/ `insert`；`remove`（按值）/ `pop`（按下标返回）/ `del` / `clear`；`[]=` 赋值。
3. **原地方法返回 `None`**：`sort`、`reverse`、`append`、`extend` 等都不返回自身，`x = x.sort()` 是 bug。
4. **`sort` vs `sorted`**：前者原地返回 `None`，后者返回新列表。
5. **查的差别**：`index()` 找不到抛 `ValueError`，`count()` 返回 0；dict 的 `d[k]` 抛 `KeyError` 而 `d.get(k)` 返回 `None`。
6. **tuple 不可变是浅层的**：`([1],)` 里的列表照样能改；`(5)` 不是元组，`(5,)` 才是。
7. **set 的价值在运算与 O(1) 成员判断**；`{}` 是空 dict，空集要写 `set()`；用 `discard` 而非 `remove`。
8. **dict 遍历**：默认遍历 key，`items()` 最常用；**遍历时不能增删 key**，要遍历 `list(d.keys())`；`in` 检查的是 key 不是 value。
9. **切片**左闭右开、支持步长与负索引、越界静默返回空；**切片赋值可改变长度**；切片返回新对象。
10. **遍历方式**：只需要值直接 `for`，需要下标用 `enumerate`，修改元素用 `enumerate` 或 `range(len())`，多序列用 `zip`（3.10+ 有 `strict=`）。
11. **三大坑**：`[[]] * 3` 引用共享、可变默认参数、返回内部可变对象。
12. **collections**：`defaultdict` 消除"先判断再赋值"；`Counter` 做计数与 Top N（不存在的键返回 0）；`deque` 提供 O(1) 双端操作（`popleft` 是 BFS/滑动窗口首选）；`namedtuple` 给元组加字段名（`typing.NamedTuple` 支持注解与方法，更推荐）；`OrderedDict` 在 3.7+ 大多可由普通 dict 替代。
13. **额外陷阱**：`dict.fromkeys(keys, [])` 的所有 value 共享同一列表，必须用字典推导式 `{k: [] for k in keys}`。

       修复一：`def f(item, target=None): target = target if target is not None else []`（推荐）。
       修复二：`def f(item, target=()): target = list(target)`。
       选 `None` 更常见是因为 `None` 是明确的"未提供"信号，且任何非 None 值（包括用户真传的列表、空元组 `()`）都能正确处理；而 `()` 方案必须额外写 `list()` 复制，容易漏。

    3. 输出 `{'k': 1}`。`get_cache()` 返回的是函数内部那个 dict 本身，`c1` 和函数里的 `cache` 是同一对象，`c1["k"] = 1` 直接改了内部状态，且下次调用又返回同一个对象（因为函数局部变量 `cache` 已随函数结束销毁……实际上这里每次调用都新建 dict，所以第二次调用返回的是**新**的空字典）。

       修正理解：由于 `cache` 是函数局部变量，函数返回后它被销毁，但返回的引用让该对象继续存活。每次调用 `get_cache()` 都会创建一个**新的** dict，所以输出应为 `{}`。真正的问题是：**返回的对象被外部持有后，外部可修改它**——如果函数改成带闭包或使用全局/类属性，就会真正出现跨调用污染。

       正确写法：`def get_cache(): return {}`（每次新建新 dict），或返回不可变对象，或需要共享状态时显式用类属性管理并提供 `copy()` 接口。

    4. 参考实现：
       ```python
       from collections import Counter

       def dup_items(items):
           return [k for k, c in Counter(items).items() if c > 1]
       ```
       注意 `Counter` 的字典在 3.7+ 保插入序，所以"首次出现顺序"天然满足。
       内存敏感场景：`Counter` 会为每个**不同**元素建一条记录，若元素基数极高（如百万级唯一 ID），`Counter` 自身就吃掉大量内存，此时改用流式两遍扫描——第一遍用 `Counter` 只统计，或改用 `set` 做两次遍历（先 `set(items)` 求唯一集合，再遍历 items 命中集合时记录），内存降到 O(唯一基数)，更省的是外部排序（sort + 相邻比较）只占 O(n) 磁盘/内存且不需要哈希表。

    5. 设 `s = [1,2,3,4,5,6]`：
       - 前 3 个：`s[:3]` → `[1, 2, 3]`
       - 后 3 个：`s[-3:]` → `[4, 5, 6]`
       - 偶数下标：`s[::2]` → `[1, 3, 5]`
       - 逆序：`s[::-1]` → `[6, 5, 4, 3, 2, 1]`
       - `s[-2:]` → `[5, 6]`
       - 越界：`s[10:20]` → `[]`（**静默返回空，不报错**，因此动态计算边界时要自己校验）

    6. `list.pop(0)` 需要把剩余元素整体前移一位，时间复杂度 O(n)，队列长度 n 意味着整体 O(n²)；`deque.popleft()` 是 O(1)，整体 O(n)。
       BFS 示例：
       ```python
       from collections import deque

       def bfs(graph, start):
           visited = {start}
           queue = deque([start])
           order = []
           while queue:
               node = queue.popleft()       # O(1)
               order.append(node)
               for nxt in graph.get(node, []):
                   if nxt not in visited:
                       visited.add(nxt)
                       queue.append(nxt)     # O(1)
           return order
       ```
       滑动窗口同理：窗口左端滑出用 `popleft`，右端滑入用 `append`，都是 O(1)。

    7. 问题：遍历 dict 时删除 key，会抛 `RuntimeError: dictionary changed size during iteration`（`d[k] > 1` 成立时在 `del` 那一刻报错）。
       三种修复：
       ```python
       # 方式一：遍历 key 列表副本
       for k in list(d.keys()):
           if d[k] > 1:
               del d[k]

       # 方式二：构建新字典
       d = {k: v for k, v in d.items() if v <= 1}

       # 方式三：按键集合先收集要删的，再统一删
       to_remove = {k for k, v in d.items() if v > 1}
       for k in to_remove:
           del d[k]
       ```
       方式二最简洁；方式一适合要打印过程或做其他副作用的场景。

    8. 取舍：
       - **`namedtuple`/`typing.NamedTuple`**：数据量极大（百万级实例）、要求极致内存与创建速度、且不需要复杂行为时。内存约为普通类的 1/3，因为它是 tuple 子类，没有 `__dict__`。适合日志记录点、解析结果行、数据库行的轻量表示。
       - **普通类**：需要方法、属性可变、需要校验、需要继承体系时。
       - **`dataclasses.dataclass`**：现代 Python（3.7+）的首选——自动生成 `__init__`、`__repr__`、`__eq__`，支持类型注解、默认值、`frozen=True`（不可变且可哈希）、`order=True`（可排序）、`field(default_factory=...)`（可变默认值）。开销与普通类接近但代码量大幅减少，工程上应优先于 `namedtuple`。
       - 结论：只读数据记录且极端关注性能用 `namedtuple`；其余情况用 `dataclass`；需要自定义行为逻辑用普通类。
